Panel Assistant 1.0.6 fixes the Repairs that left panels stuck during setup or an update, and makes moving a panel over from the Home Assistant Companion app work first time.

### Fixed

- **Repairs you can finish.** When setup stalls or a panel refuses an app update, the Repair now says what to check, such as the panel being offline, network debugging being unreachable or Android not yet confirming device administrator access, and shows its progress when you try again ([#38](https://github.com/panel-assistant/ha-integration/issues/38)). A panel still on the old ha-paneld app gets the steps to export its settings, install the current app and import them again. The permissions Repair keeps Install packages on its list when a later check can only see some permissions.
- **Moving from the Companion app.** A panel installed from the Companion app offer now keeps its identity, so it connects to Home Assistant and its entities appear. Setup waits while you finish the panel's own setup page and carries on by itself once it is done. The install dialog mentions the Meta Portal only when the panel is one.
- **Apps from your previous setup.** A new Repair lists the apps left from the setup the panel used before Panel Assistant and opens the panel's Install page, where you confirm each removal. Select Ignore to keep them.
- **Quieter logs and a faster start.** A normal Home Assistant shutdown no longer logs that panels lost their connection, panel log lines stay on one line, and the check against another Home Assistant closes its connection cleanly. The USB installer link is checked when you open it, so Home Assistant no longer waits for that check at startup.
