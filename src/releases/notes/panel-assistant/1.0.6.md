Panel Assistant 1.0.6 makes moving a panel over from the Home Assistant Companion app work first time, says what to check when setup or an update stops, and keeps Home Assistant's log quieter.

### Fixed

- **Moving from the Companion app.** A panel installed from the Companion app offer now keeps its identity, so it connects to Home Assistant and its entities appear. Setup waits while you finish the panel's own setup page and carries on by itself once it is done. The install dialog mentions the Meta Portal only when the panel is one.
- **Your Area and the apps you used before.** A newly migrated panel can take its Area from the setup it replaces. A new Repair lists the apps left from that setup and opens the panel's Install page, where you confirm each removal. Select Ignore to keep them.
- **Repairs that say what to check.** When setup stalls or a panel refuses an app update, the Repair says what to check and shows retry progress when it can. A panel still on the old ha-paneld app gets the steps to export its settings, install the current app and import them again.
- **One restart, quieter logs.** After a Marketplace or HACS update you are asked to restart Home Assistant once. A normal Home Assistant shutdown no longer logs that panels lost their connection, panel log lines stay on one line, and the check against another Home Assistant closes its connection cleanly.
- **Starting without internet.** The USB installer link is checked when you open it, so Home Assistant no longer waits for that check at startup.
- **Permissions Repair.** Install packages stays on the list of permissions you turned off when a later check can only see some of them.
