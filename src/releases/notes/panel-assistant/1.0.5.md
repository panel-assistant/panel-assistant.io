Panel Assistant 1.0.5 improves the Finish setting up Repair, keeps a panel's entities steady while it reconnects, and includes the 1.0.5 Android app with support for more panel hardware.

### New

- **More panel hardware, with panel app 1.0.5.** The NSPanel Pro Gen2 now has its own profile, so its two relays appear in Home Assistant. Thank you to [@cyraxx](https://github.com/cyraxx), who worked out the relay settings, tested them on their own panel and reported that everything else worked too ([android #215](https://github.com/panel-assistant/android/issues/215)). The Electron SMT97T's two relays and the light strip on some Electron WF1589T panels are now supported as well. Thank you to [@GrisuBerlin](https://github.com/GrisuBerlin), who supplied their details ([#37](https://github.com/panel-assistant/ha-integration/issues/37), [#42](https://github.com/panel-assistant/ha-integration/issues/42)).

- **Every local address handed to a new panel.** Setting up a panel now hands it Home Assistant's internal URL and each of its local network addresses, not just one, so a panel running app 1.0.5 can keep the first that answers from its own network. Home Assistant's external or cloud address is never sent, and nothing extra is sent when Home Assistant serves HTTPS itself.

### Fixed

- **Finish setting up, or stop asking.** Home Assistant hides Ignore on a Repair that offers a fix, so a Finish setting up Repair whose Submit could not succeed stayed for good ([#38](https://github.com/panel-assistant/ha-integration/issues/38)). The Repair now opens with two choices: Finish the setup now, or Stop asking. Stop asking clears the Repair and changes nothing on the panel, and the next install or update you start runs the step again. When Submit cannot finish, the message now ends with the check that stopped it, which also makes a bug report clearer.
- **No flashes of unavailable.** Each time a panel's connection to Home Assistant dropped and came back, all of its entities went unavailable until the new connection had synced ([#25](https://github.com/panel-assistant/ha-integration/issues/25)). Panel Assistant now keeps the last synced state for up to a minute, so a quick reconnect leaves the entity history clean.
- **Restarts no longer skip setup.** If Home Assistant restarted while a panel was installing an update, the update forgot the setup step it still owed. It now remembers it, and the Finish setting up Repair asks you to run it.
- **Clearer help when the Android Debug Bridge is off.** When a panel answers but its Android Debug Bridge is off, the message now says more plainly how to turn it back on from the panel's own settings page.
