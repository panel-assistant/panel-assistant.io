Panel Assistant 1.0.4 has no user-facing features. It makes the changes asked for in the review of our submission to the HACS default list. Panels keep the 1.0.3 Android app.

### What the review changed

- **Panel setup only when you ask for it.** After a panel's own setup finished, Panel Assistant made its app the device administrator and applied the settings for that make of panel from its regular poll, once for each app build, and a panel added without an install got them on its first poll. These changes now happen only during an install or update you start. If an install or update cannot finish that last step, the new Finish setting up Repair explains what it changes on the panel and runs it only when you select Submit.
- **Looking for panels other integrations know.** Panel Assistant now checks for panels set up by other integrations only when you open Add panel, not every time Home Assistant starts.
- **Camera and microphone on Android 9 and older.** Panel Assistant 1.0.3 began leaving alone any permission someone had turned off on the panel. On Android 9 and older, a permission nobody has decided yet does not appear in the list Android reports, so 1.0.3 skipped it, and a fresh install over the network or USB left the camera and microphone off. 1.0.4 again grants a permission Android does not list, while still keeping any choice made on the panel.
- **No approval prompt on the Shelly Wall Display.** When Home Assistant reconnected to a Shelly Wall Display, Panel Assistant could ask for approval on the panel's screen and restart the app's helper on the panel. It now only watches the dashboard over network ADB, so a reconnect asks for nothing on the panel.
- **Home Assistant stays responsive.** Assembling large downloads, uploads and panel replies such as a stored backup, reading the pages the sidebar shows, checking a new ADB key, looking up the temporary folder for a WebView update, and loading some of Panel Assistant's own code happened on Home Assistant's event loop, which could briefly pause other integrations on a slow host. They now run in the background or when Panel Assistant loads.
