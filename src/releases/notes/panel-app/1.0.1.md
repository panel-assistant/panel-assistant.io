This is the first update to the panel app since 1.0. The biggest change is presence: auto-sleep now learns your panel's proximity sensor from everyday touches, so setting up proximity has become optional. There is also a new way to tune the microphone for voice, and a set of fixes for things that came up in the first days after 1.0, including WebView updates from Panel Assistant and a few ways a fresh install could get stuck. If something misbehaves, please open an issue with the panel model and what you saw.

Pairs with Panel Assistant 1.0.1, the Home Assistant integration.

### New

- **Presence learns from your touches.** The auto-sleep activity source on the Configure page is replaced by Presence, which you can also change from Home Assistant. On a panel with a proximity sensor it starts on Automatic, which learns the sensor from your touches, so the proximity wizard is no longer needed. Hybrid starts from the wizard's readings and keeps learning, Manual uses the wizard's readings alone, Home Assistant device follows presence sensors in Home Assistant, and Off uses only the touch delay. Your earlier setting carries across: a panel you set up with the wizard keeps using those readings. With Home Assistant device you can now pick motion, occupancy or presence sensors from any Area, helpers included, instead of the ones found in the panel's Area, and if none can be used auto-sleep falls back to the touch delay instead of stopping.
- **Tune the microphone from the Voice card.** While voice is on, the Voice card shows a live microphone level, a wake word test that shows how close each attempt came, and what Assist heard and answered last time. Tune the microphone walks you through a quiet room, your normal voice and the wake word from across the room, then suggests a microphone gain and wake word sensitivity; Cancel puts your old values back. These screens are in English for now.
- **Early support for the Shelly Wall Display XL.** The panel app recognises the XL and maps its buttons and proximity sensor. This is based on captured input from an XL rather than one on my desk, so please tell me how it goes.
- **Shelly Wall Display X2i relays.** Where the X2i's firmware lets the panel app switch its built-in relays, they now show in Home Assistant, without root. They only switch while the panel is mains powered.
- **The network warning shows its working.** When the panel warns about its network path to Home Assistant, it now gives the figures behind the warning: how many network checks were lost and how long they took.

### Changed

- **The Shelly Wall Display X2i listens on both microphone channels.** It takes whichever channel hears you better instead of averaging the two. If a panel's microphone refuses the format it asks for, or stops delivering sound, the panel app reopens it on the standard setting rather than going deaf.

### Fixed

- **WebView updates from Panel Assistant work.** The panel app refused the WebView install requests Panel Assistant 1.0.0 sends, so the update timed out. It now accepts them, and it checks there is enough free storage to finish before it starts. The panel's daily maintenance also clears out leftover update files that could slowly fill the storage.
- **Fresh installs get stuck less.** A sign-in on the panel whose link had expired now starts again by itself instead of sitting on the error. A panel reached by its network host name is no longer refused with "host not allowed". When the dashboard covers the setup wizard while a setup question is still open, the waiting screen now has a Set up button that takes you back to it. And a Sonoff NSPanel Pro whose firmware shows Android's navigation bar keeps that bar instead of getting a second one drawn on top.
- **A brief network drop no longer reloads the dashboard.** When the network comes back the panel keeps the page and lets Home Assistant reconnect it in place. When a reload really is needed, the reconnecting notice is in your language.
- **Auto-sleep and proximity are better behaved.** Proximity setup only asks for your attention while Wake on wave is on, so a panel that does not use it no longer raises a proximity setup Repair, and an existing one clears after the update. A strong first wave during setup no longer makes later, smaller waves fail, and on the Sonoff NSPanel 86 a hand held over the sensor no longer makes the panel report its proximity sensor lost. A panel that can only dim its screen no longer reports it as off, and a touch or switching auto-sleep off brings the brightness back. Back from Home Assistant wakes the screen first.
- **The Companion settings check works on more panels.** On rooted panels running Android 11 or later the check can now read the Home Assistant Companion app's settings, including ones the Companion app has only just written.
- **Rooted panels with an older root helper update cleanly.** A root helper installed into the system partition by an older setup now moves to the panel app's own helper, and a move cut short by a power loss or reboot finishes on the next start. Panel Assistant's maintenance route on rooted panels also recovers by itself when the helper could not take it over at startup, instead of staying unavailable until a restart.
- **Status screens fit at large font sizes.** With a large system font, the panel's status screens, notices and readings fit on screen and every button can be reached, in every language.
- **Quieter panel logs.** Repeated warnings, and messages some panels' firmware produces that are known to be harmless, are now collapsed instead of filling the log.
