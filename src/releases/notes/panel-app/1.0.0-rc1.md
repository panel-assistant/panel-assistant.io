This is the first release candidate of the panel app's 1.0, the Android app that Panel Assistant installs on your panels. Please open an issue with the panel model and what you saw if something breaks. The story of 1.0 is that MQTT and the old app are gone for good, so this release only works with panels that Panel Assistant 0.9.0 has already moved. In exchange the panel and Panel Assistant now talk over one connection for everything, including the sidebar, updates and voice, and that is what makes most of the changes below possible. A lot changed; I have listed what you will notice rather than every commit.

Pairs with Panel Assistant 1.0.0-rc1, the Home Assistant integration.

### Before you update

- **This is a release candidate.** Once Panel Assistant 1.0.0-rc1 is installed, it offers this release to your panels as a normal update.
- **Update Panel Assistant to 1.0.0-rc1 first.** 1.0 changes how the panel and Panel Assistant talk to each other, and Panel Assistant 1.0.0-rc1 speaks only the new way. It offers this release candidate to every panel it manages without a per-panel pre-release setting. To see its release candidate in HACS, turn on the **Pre-release** switch of the Panel Assistant device in the HACS integration (Settings, Devices & services, HACS; the switch is under Diagnostic and disabled until you enable it).
- **Every panel must already be on v0.9.11 with Panel Assistant 0.9.0.** 1.0 has no MQTT and does not move a panel off the old app id. A panel still on MQTT or the old app is refused, with a Repair asking you to go through Panel Assistant 0.9.0 first.
- **There is no way back to 0.9.** Android does not install an older build over a newer one. Take a settings backup from the panel's Install page before you update if you want one.
- **A panel Panel Assistant cannot reach over ADB updates with one tap on the panel.** Install and update now give the panel app permission to install packages, so a panel without network ADB installs its own update after someone taps Install in Android's confirmation on the panel. Reconnecting the panel by USB brings back updates that need no tap.
- **Two entities are gone.** The separate camera snapshot image entity is removed; use the panel's camera entity. On a panel with a speaker the separate volume number is removed; use the media player's volume. Automations that used either need changing, and Panel Assistant raises a Repair naming them.

### New

- **Entity reading shows its progress.** Setup and the panel's hold screen show an approximate entity total and a progress bar when Panel Assistant supplies the count or the panel has a previous scan. The final count replaces the estimate when reading finishes.
- **Meta Portal support.** The panel app now recognises the Meta Portal 10-inch (2nd gen), with its camera, microphone, light sensor and native screen density, and other Portal models through a family profile. On a Portal the screen sleeps through Android's screen timeout, the panel launcher opens instead of Meta's clock, the hardware microphone privacy switch is followed, and the panel app stays the home screen even where Meta's firmware keeps showing Android's Home chooser.
- **Screenshots and display sizing on panels without root.** On Android 11 or later, a panel without root, such as the Shelly Wall Display X2i, now shows its live screenshot in Panel Assistant, and a tap on it reaches the panel and comes back with a fresh picture. Text size and display density can be set from the Install page on the same panels, where the firmware allows it. None of this uses ADB.
- **See the voice conversation on screen.** After the wake word, a card at the foot of the dashboard shows whether the panel is listening, thinking or replying, quotes what it heard, writes out the reply as it arrives and ticks off Heard, Understood and Answered. If something fails, the card says what went wrong in plain words.
- **Say "stop" to end a reply, an announcement or a ringing timer.** While the panel thinks or speaks it also listens for "stop", silences the sound and goes back to waiting for the wake word. A voice request Home Assistant does not pick up within four seconds now gives up instead of hanging for two minutes.
- **Download community wake words.** The Voice card on the Configure page offers community wake words from a list that ships with the app. It shows each one's author and licence before downloading, shows progress, and checks every file against the list before using it.
- **Show dashboard and Back from Home Assistant.** With Panel Assistant 1.0.0-rc1, each panel offers a Show dashboard button, which brings the dashboard to the front, and a Back button, which does what Android's Back does. Back is offered only while the panel can perform it: its accessibility service is running, or the panel is rooted.
- **Panel voice commands.** With Panel Assistant 1.0.0-rc1, say "show the kitchen page", "show Android settings" or "show the launcher" to the panel you are speaking to, in every language Panel Assistant ships.
- **Panel models start with their own sensible defaults.** Each panel model's profile can now set starting values, such as dashboard zoom and brightness range, and recommend a display size; a Meta Portal 10 starts at 85 percent dashboard zoom, for example. A setting you have already changed keeps your choice.
- **A panel's device links to the same hardware in other integrations.** The panel now reports its Wi-Fi and Ethernet hardware addresses, and Panel Assistant adds them to the panel's device, so a device another integration made for the same panel, such as the Shelly integration's for a Shelly Wall Display, shows as linked on the device page.
- **USB debugging shows as a diagnostic.** Home Assistant now shows whether USB debugging is on for each panel as a diagnostic entity, so you can see whether a panel can still be reached for updates, and the panel shows a notice on screen when it changes.
- **Dashboard theme, idle return and screen timeout from Home Assistant.** With a Panel Assistant that offers them, Home Assistant can show and change the dashboard theme, the idle return to home and Android's screen timeout, which is the screensaver delay on a TV, and a change on either side shows on the other at once. The screen timeout can be changed only while Prevent idle dim is off.

### Changed

- **MQTT is removed.** The panel app no longer has a broker setting or an MQTT step in setup: every panel talks to Home Assistant through Panel Assistant's own connection, and button presses, auto-sleep activity, the camera and Zigbee gateway health reach Home Assistant that way.
- **The Panel Assistant sidebar shows the panel's own pages over its connection to Home Assistant.** In the sidebar, the panel's pages now load and talk to the panel through its existing Home Assistant connection instead of Home Assistant fetching them from the panel, so a panel that Home Assistant cannot reach directly, on another network segment or behind a firewall, can still be viewed and configured from the sidebar. While the panel restarts the sidebar retries on its own. Opening the panel at its own address on port 8888 works as before.
- **Settings apply as you change them.** The Configure page no longer has a Save button: each change is sent as soon as you make it, a change made from Home Assistant or another browser shows on the page within a second, and the page says whether a change is already on the dashboard or still being applied. Camera, audio source, boot chime and idle-dim changes from Home Assistant are reported applied only once they really are.
- **Voice starts on where the panel has a known microphone.** A panel whose model has a proven microphone, such as the Sonoff NSPanel Pro, the Electron WF1589T, the Tuya TPA10, the Shelly Wall Display X2i and the Meta Portal 10, starts with the voice assistant on. A panel where voice was already turned on or off keeps that choice. Panel Assistant can now turn voice on too: enabling the panel's Assist entity in Home Assistant turns the voice assistant on.
- **New panels show Home Assistant's navigation.** **Hide Home Assistant navigation** on the Configure page's Dashboard card is now off on a new panel, so its sidebar and header stay reachable. A panel you update keeps the setting as it was.
- **Shelly Wall Display screens switch fully off.** On a Shelly Wall Display, including the X2i, the panel app now turns the backlight off through Shelly's own launcher instead of only dimming it, and the first touch on the dark screen wakes it without pressing anything on the dashboard. Shelly's own auto-brightness is kept off so the brightness you set is the one shown.
- **Shelly Wall Display navigation bar starts hidden.** A newly set up Shelly Wall Display starts with the navigation bar on Swipe reveal: swipe up from the bottom edge to show it. A panel already set up keeps its setting.
- **Clearer names in Android's Home app list.** The panel's own app drawer is now called Panel launcher instead of Panel admin, and the dashboard entry is called Home Assistant Dashboard instead of HA dashboard, in Android's Home app list, its Home chooser and the Launcher app setting.
- **Choosing the dashboard in setup is one tap.** When your Home Assistant account has no default dashboard, the panel's setup now starts on Home Assistant's own Overview instead of an empty choice, and setup lists Home Assistant's built-in dashboards by the names Home Assistant gives them. The panel's not-set-up screen no longer mentions an address it does not show.
- **Camera snapshots use the Home Assistant camera entity.** The separate image entity and panel JPEG endpoint are retired. Snapshots now come from the camera stream, which uses Home Assistant's normal timeout after a request.
- **Entity filtering is tighter and settles faster.** A filtered dashboard now also hides the devices and registry entries of entities it does not allow, and learns which entities a template card uses before it first draws. The Entities page shows when the panel is still holding the dashboard while it learns.
- **Tidier panel web pages.** Every warning and advisory on the panel's Dashboard, Configure and Entities pages now uses one notice style, and long field instructions and choice lists wrap instead of being cut off.
- **Updates follow the build number.** The panel app now compares updates by build number alone, so a newer build is never refused as a downgrade because its version name sorts lower.
- **Auto-sleep sources use a pop-up menu.** Pick the activity source on Configure from a menu instead of a list of radio buttons.
- **Component versions use a pop-up menu.** Pick the HA Companion version on Install from a menu instead of a list of radio buttons; a version the panel cannot use still shows its full explanation.
- **The network warning setting is on the System card.** It controls the Home Assistant connection notice and now sits with the other system settings on Configure.
- **Refreshed Pickles artwork** on the panel's web pages.
- **Panel app updates belong to Panel Assistant.** The panel app's own Install page no longer offers a separate panel app version picker; choose its update in Home Assistant.
- **Uploaded wake words need approval in Hardened mode.** Importing your own wake word through the panel's web address now asks for approval on the panel, which requires physical access and cannot be approved remotely; downloads from the community list and imports through a Home Assistant administrator's sidebar keep working without that extra step.

### Fixed

- **Text on a Meta Portal matches every other panel.** The Portal's own font is wider than the Roboto every other panel draws, so the panel app now uses a copy of Roboto that ships with it on the Portal: in its notices, such as the Home Assistant restart card, and on its own pages opened on the Portal. Other panels, and the pages in a browser or the Panel Assistant sidebar, are unchanged.
- **Reconnect sign-in works from the sidebar.** Reconnect opens Home Assistant sign-in in a separate window, and Configure follows the new account once sign-in finishes.
- **Basic view keeps a blocked setting's prerequisites within reach.** If automatic brightness needs a light source, or auto-sleep needs a source or Area, those choices stay visible without switching to Advanced.
- **Configure remembers your view in the sidebar.** Basic or Advanced, Descriptions, expanded settings and the setting filter survive a reload or a switch to another panel.
- **Backup downloads have distinct names.** Downloading several backups, even in quick succession, no longer gives them the same name.
- **Restore explains when it is waiting for approval.** In Hardened mode, the Install page tells you where to approve the restore on the panel and says whether approval was denied or timed out, with nothing changed.
- **Settings imports distinguish applied changes from pending ones.** A setting still being applied is listed as pending, and a restore that changes saved panel state before another step fails reports a partial result.
- **Meta Portal gets past its startup permission page.** After a reboot, the panel returns from Meta's denied overlay-permission page even when settings take longer to load.
- **Whole-number settings round consistently.** Automatic brightness levels and response, and idle return, round changes from Home Assistant the same way as Configure.
- **The dashboard starts in its chosen theme.** Its loading screen and first paint follow the panel's Dark or Light choice too.
- **The restart notice survives a connection change.** Refreshing the connection to the same Home Assistant keeps its restart notice until Home Assistant reports its state again.
- **Turning network debugging off waits for a slow panel.** A panel that takes longer to confirm debugging has stopped no longer reports a false failure.
- **Process readings handle unusual app names.** A process name containing quotes or other special characters no longer breaks the CPU and memory readings.
- Auto-sleep reports an authentication failure only after Home Assistant rejects the sign-in. A temporary failure to obtain a token now recovers when the connection returns.
- The navigation bar follows its mode and sits on the bottom edge of the screen on Android 8.1 panels such as the Sonoff NSPanel Pro. Once set to Always on it could not be changed to another mode, it was drawn a bar-height above the edge with an empty band beneath it, and on a panel moved from the old app the band could stay in every mode.
- The bar's Launcher button opens the panel launcher every time. After a page opened from the launcher, such as Panel Assistant, it could do nothing until recent apps were cleared.
- Synchronised voice reconnects as soon as its audio connection closes, while panel controls stay connected.
- Synchronised voice can connect after a slow initial state sample without exhausting its handshake window.
- Display sizing and launcher controls wait for a slow root helper's reply instead of reporting a false failure or repeating the operation.
- Logs queued during an outage keep the time they were captured when they reach the collector.
- Pending install approvals end with their connection. Refused screen brightness and RGB LED writes report failure, and failed LED effects become unavailable until output is confirmed again.
- Configure keeps local Area overrides visible and refreshes dashboard choices after sign-in. Low-memory recovery preserves on-panel sign-in forms, and revision restores name settings the panel can no longer apply.
- Dashboard responsiveness keeps its live metrics without writing retired performance history.
- **The right WebView for the Smatek S9E and the Electron WF2489T.** The S9E profile now names the 64-bit replacement WebView its 64-bit firmware needs, instead of a 32-bit build that cannot serve the app. The WF2489T profile no longer names a replacement WebView at all, because that panel updates Google's WebView from the Play Store.
- **The Smatek S9E switches its backlight off.** Switching the screen off used to dim it to black with the backlight still lit, and the screen switch in Home Assistant could turn itself back on a few minutes later. The panel app now powers the S9E's backlight off, the switch stays off, and a touch still wakes the screen. Contributed by @merdok.
- **Panel Assistant can remove the app when it is a device admin.** Android refuses to uninstall an app that has been made a device admin in its settings, so removing the panel app failed on such a panel. The app now gives up device admin when Panel Assistant asks, just before removing it.
- **The panel says when it cannot reach Home Assistant.** When the dashboard drops and the panel has no session to Panel Assistant, it shows Cannot reach Home Assistant with a retry timer instead of a bare Offline. The reconnect card also comes back correctly after the dashboard's browser engine crashes or the screen goes dark mid-load.
- **The restart notice knows when a restart is late.** While Home Assistant restarts, the notice says so when the restart runs past its usual time, even while the dashboard reloads, and gives way if Home Assistant never comes back.
- **No more dashboard stuck on Preparing.** After an update, a theme change or choosing a new home dashboard, the panel brings its existing dashboard forward instead of opening a second copy that could sit on Preparing dashboard until Home was pressed.
- **The panel's dashboard theme is respected.** Choosing Dark or Light for the panel's dashboard now works even when the panel's Home Assistant user has its own theme saved.
- **Kiosk mode reports and keeps its real state.** Turning kiosk mode on or off quickly, or when the panel's storage refuses a write, no longer leaves the panel locked when it shows unlocked or the reverse, and the way out of kiosk mode always works.
- **Home Assistant shows panel sensors accurately.** A sensor you hide on the panel's Configure page becomes unavailable in Home Assistant straight away, a sensor with no reading shows as unknown together with the reason, and the light-sensor picker says when sensors were found but none is reporting a light level. A panel model with no physical keys, such as the Shelly Wall Display X2i, no longer gets a button entity that would stay unknown forever.
- **The panel follows an Area move at once.** When Panel Assistant reports that the panel was moved to another Area in Home Assistant, the panel reads its Area again straight away instead of waiting for its scheduled check; an Area chosen on the panel itself is still kept.
- **The media player's volume no longer goes blank.** On a panel with a speaker the volume is always reported to the media player, so hiding Panel volume can no longer blank it.
- **The sidebar shows the last screenshot straight away.** In the Panel Assistant sidebar the Dashboard page shows the panel's last screenshot while a fresh one is taken, so a sleeping or slow panel no longer leaves the card empty.
- **Screen settings apply as reported.** Switching auto-sleep on from the Configure page takes effect at once, and a touch reliably wakes a screen switched off through the screen timeout.
- **Proximity calibration is kept.** A panel's saved proximity calibration now survives app updates and a backup restore, and turning on Wake on wave on a panel without a proximity sensor reports it unavailable instead of pretending.
- **Setup follows a panel that changes address.** If the panel's network address changes during setup, its setup QR code and the sign-in address shown for your phone update to match, and a sign-in that was refused is not retried when the network comes back. A freshly installed panel waiting for setup no longer covers its setup code with a notice saying Panel Assistant is required.
- **Restoring a backup onto a panel without root skips what it cannot apply.** The restore lists the settings that panel cannot apply instead of failing.
- **Voice settings stay current.** The list of voice pipelines is fetched again when the panel's Home Assistant connection changes, and a new audio source takes effect as soon as the camera stream lets go of the microphone.
- **Vendor apps are tamed on the first try on a slow panel.** On a panel whose root helper takes more than half a second to stop or disable an app, each action used to run a second time through su, and the whole taming pass repeated for several minutes after the app started. The helper is now given the time those commands take.
- **Log shipping reports an outage once.** While the log collector cannot be reached, the panel logs the first failed attempt and, when it reconnects, one line saying how many attempts failed and the last reason, instead of a warning every few seconds.
- **Translation corrections** across every shipped language, including the setup screens, the Voice card and the diagnostics page.
