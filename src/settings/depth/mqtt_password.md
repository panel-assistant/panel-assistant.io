The password for [Username](#mqtt_user). The form never shows the stored password, so the field is empty each time you open it, and leaving it empty keeps the current one. To remove the password, clear the user name, which clears both. With [security mode](/manage/security-mode/) set to hardened, changing the broker URL also discards the stored password unless you enter it again in the same save. Like the user name, it is not copied to other panels by default.
