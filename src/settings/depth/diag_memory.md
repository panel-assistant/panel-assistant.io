This row has no value to edit. Its switch adds a diagnostic sensor in Home Assistant with the share of the panel's RAM in use. It is off by default. It works on every panel because the source is always readable, and changes smaller than 3 percentage points are not published.

Android keeps memory in use for caches, so a high value on its own is normal. A value that climbs steadily over days is the pattern worth noticing.
