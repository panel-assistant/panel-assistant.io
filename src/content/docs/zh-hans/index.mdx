<Split title="好硬件，却被软件拖了后腿">

Android 墙面面板的硬件确实不错，配套软件却确实糟糕。仪表盘卡顿，点击没反应，厂商自带应用抢占屏幕，而且每家厂商都要求使用不同的应用、按不同的步骤设置。大多数人只能忍受，因为一块没有按钮、也无法可靠重置的面板，一旦弄坏，代价不小。

Panel Assistant 是免费且开源的解决办法。它只做一件事：让 Home Assistant 仪表盘在墙上快速运行，省心好用。你拥有的每一块面板，都能以相同的方式从 Home Assistant 设置和管理，无需手动维护、调校或微调。

</Split>

<Spotlight
  title="只接收仪表盘用到的实体"
  figure="10–100×"
  caption="到达面板的 Home Assistant 状态数据流量降幅，测量来自真实家庭"
>

墙面面板上的仪表盘通常会接收家中每一次状态变化，无论是否显示对应实体。在规模较大的系统中，性能较弱的面板会花时间解析数千个从不显示的实体，这通常就是卡顿的原因。

Panel Assistant 的实体筛选器会读取仪表盘配置，并观察运行中的仪表盘，了解它真正依赖哪些实体，然后要求 Home Assistant 只发送这些实体。Home Assistant 会在发送数据之前完成筛选，其余数据根本不会到达面板。

这就决定了面板是迟迟没有反应，还是一触即应。[了解工作原理及启用方法](/zh-hans/manage/performance/)。

</Spotlight>

<Split title="无论固件状况如何，都让面板运行起来">

大多数面板从海外电商平台寄来时，只附有简薄的说明书，厂商也不保证它能运行自带应用以外的软件。等你花了钱、搭上几个夜晚，才知道能不能用。Panel Assistant 希望消除这种不确定性：购买前先 [检查你的型号](/zh-hans/install/supported-panels/)，这样到货后就有经过测试、可重复的方式让它运行起来。

任何面板最难的都是最初那一小时。Panel Assistant 在 Home Assistant 内替你完成这部分工作。如果面板已经连上网络，向集成提供地址，剩下的交给它。如果面板还在盒子里，用 USB 线连接笔记本电脑，在上墙之前直接从浏览器安装。两种方式都只需在面板上批准一次提示，然后看着安装完成。

</Split>

<Split title="面板不在列表中？描述它，就能加入">

Panel Assistant 的硬件支持靠数据，而非代码。每个型号都由配置文件描述：如何识别面板、它有哪些硬件，以及通过哪些安全途径驱动屏幕、LED、继电器和传感器。配置文件是纯文本，在浏览器中即可编辑和验证，无需开发工具，也无需重新构建。即使项目从未见过的面板，也能通过保守的通用配置文件获得基本功能；你可以继续补充它的能力，并分享成果。

</Split>

<Split title="测量得出的性能">

廉价面板运行缓慢有其原因，Panel Assistant 会把原因展示出来。面板状态页面会测量点击延迟、达到可交互状态所需时间、主线程阻塞、意外重新加载、每秒状态更新次数，以及造成最多更新的三个实体，同时显示 CPU、内存和温度。“可能原因”一行会综合这些数据，告诉你是什么拖慢了面板。

</Split>

<Split title="装好，就放心用">

墙面面板应像电灯开关一样：一直可用，无需照看。Panel Assistant 会学习房间的正常光线并随之调暗，学习接近传感器，让挥手能唤醒屏幕而路过的猫不会；夜间屏幕关闭时释放内存，并在重启后自动重新打开上次正常运行的仪表盘。

</Split>

<Split title="让厂商软件服帖">

Panel Assistant 接管主屏幕，为没有按钮的面板提供屏幕上的导航方式。对于出厂浏览器引擎老旧多年的面板，它保留已知可靠的引擎，同时防止厂商控制小部件覆盖你的仪表盘；设计上则拒绝触碰任何维持面板正常运行所必需的组件。

</Split>
