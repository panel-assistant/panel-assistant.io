Panel Assistant 由两部分组成。一部分在 Home Assistant 中运行，是你看到和使用的部分。另一部分在每台面板上运行，让面板保持快速响应。

## 在 Home Assistant 中：集成

集成就是你通过 HACS 安装的部分。你在这里添加面板，每台面板都会以设备的形式显示，并拥有自己的状态和诊断信息。侧边栏中的 Panel Assistant 页面会集中显示所有面板，以及每台面板是否可连接、正在运行哪个版本、是否有需要关注的问题。

它也是安装程序。提供新面板的地址，或者将新面板连接到笔记本电脑，它就会检查已有内容、安装面板应用、启动应用，然后才创建设备。如果面板已经在运行此应用，它会直接接入该面板。

## 在面板上：应用

墙面面板是一台小型 Android 计算机，而大多数面板显得缓慢，是因为随附的软件。Panel Assistant 用自己的应用替换其中关键的部分，这个应用负责三件事。

- **显示你的仪表盘。** 应用自行加载你现有的 Home Assistant 仪表盘，确定这个仪表盘实际显示哪些实体，并仅向 Home Assistant 请求这些实体。对于廉价面板来说，这正是响应有延迟与无延迟之间的大部分差别所在。
- **控制面板的硬件。** 屏幕、屏幕亮度和休眠、LED、按钮、继电器、接近传感器和光线传感器，以及该型号具备的其他组件，都由应用直接控制，并在 Home Assistant 中作为面板设备的实体显示。每个型号都由硬件配置文件描述：它是纯文本，你可以在面板上的浏览器中阅读、编辑和验证，无需开发工具。项目从未遇到过的面板会使用保守的 Generic 配置文件启动，获得任何 Android 设备都能提供的仪表盘、传感器、亮度、音频和导航功能；随着配置文件逐步补全，它也会获得其余功能。运行中的面板会在使用每项已声明的能力之前先检查它，因此缺失的功能会显示为已锁定并附有说明，而不会保持故障状态；如果某个配置文件在启动时失败，就会回退到上一个可用的配置文件。
- **像家电一样运行。** 应用取代厂商的启动器，为没有按钮的面板提供屏幕上的导航方式，在你的网络中提供自己的状态页面，并在出错时自行恢复，因此面板安装一次后就可以放手让它运行。

这个应用叫作 ha-paneld。这个名字源于它早期作为后台辅助程序的历史，当时其他仪表盘软件依赖它运行；此后，它逐渐发展为产品在面板上的完整部分。你会在参考文档和面板自己的状态页面中遇到这个名字，了解它有助于避免困惑，但使用 Panel Assistant 时，你从来不必输入这个名字，也不必考虑它。

## 为什么它可以开源

大多数面板厂商以闭源库的形式提供硬件支持，只有厂商自己的应用获准使用这些库。ha-paneld 不使用它们。它通过自己为各型号提供的配置文件，直接控制每台面板的硬件。这需要大量工作，也是项目能够提供硬件支持的原因。同样，这也是整个产品能够免费提供的原因：其中没有厂商代码，因此没有什么阻止它以宽松许可证免费开源，并适用于所有品牌的面板。

也正因为如此，硬件支持是项目最需要帮助的地方。每台向项目反馈的面板，无论是否能正常运行，都会让下一个配置文件变得更好。参见 [选择面板](/zh-hans/install/supported-panels/)，了解目前的支持情况。

## 各部分在哪里

| 部分            | 是什么                                                        | 位置                                                                                |
| --------------- | ------------------------------------------------------------- | ----------------------------------------------------------------------------------- |
| Panel Assistant | Home Assistant 集成：安装程序、设备，以及显示所有面板的页面。 | [panel-assistant/ha-integration](https://github.com/panel-assistant/ha-integration) |
| ha-paneld       | 面板上的应用：仪表盘、硬件、启动器、状态页面。                | [panel-assistant/android](https://github.com/panel-assistant/android)               |
| 硬件配置文件    | 各型号的描述，告诉应用面板具备什么，以及如何控制它。          | [硬件参考](/zh-hans/hardware/)                                                      |
| 参考文档        | API、硬件配置文件和安全模型的详细说明。                       | [参考](/zh-hans/reference/api/)                                                     |

## 它不是什么

它面向专用墙面面板。平板电脑和手机也可以运行它，但任何带电池的设备都需要一根线缆，而且设计假设面板由市电供电，设置一次后就放手让它运行。它不是仪表盘构建工具，而是显示你已有的仪表盘。它也尚未完成：目标是普遍的硬件支持，以及无需干预地管理每台面板。
