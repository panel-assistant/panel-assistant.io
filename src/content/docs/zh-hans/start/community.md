## 这些页面上的评论

每个页面底部都有评论区。如果你有 GitHub 账户，可以直接在那里评论和回复。如果没有，请打开评论下方的**无需 GitHub 账户即可评论**，通过表单发布。无论使用哪种方式，评论都会进入 [网站的 GitHub Discussions](https://github.com/panel-assistant/panel-assistant.io/discussions)中的同一个讨论，因此更正或建议会留在相关页面旁。

## 问题和缺陷

请在 [问题跟踪器](https://panel-assistant.io/go/issues)中报告 Panel Assistant 的问题。

## 聊天

如果想快速提问或聊一聊，请加入 [Discord 服务器](https://panel-assistant.io/go/discord)。
