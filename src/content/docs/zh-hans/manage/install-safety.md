Panel Assistant 从 Home Assistant 安装和更新面板，其设计确保安装无论只运行一次，还是在中断后重新运行，都能得到相同结果。本页说明它会检查和保留哪些内容。

## 更改任何内容前先检查

两种安装程序都会在更改面板前检查面板。网络安装程序会检查面板上已有的内容，并要求你确认安装；已经运行面板应用的面板会直接接入，而非重新安装。USB 安装程序不会覆盖其他现有安装：如果已安装的恰好是所选构建，它会完成该构建的设置；如果已安装的是另一构建，它会将该构建重新连接到 Panel Assistant，而不安装更新。

发布版本来自你自己的 Home Assistant。Home Assistant 会先检查，再将其交给安装程序，因此任何未经 Home Assistant 验证的内容都不会到达面板。[通过 USB 安装](/zh-hans/install/install-over-usb/)和[添加面板](/zh-hans/install/installing-ha-paneld/)分别介绍这两种方式。

## 可以安全重试

安装中途停止后，可以重新运行。通过 USB 安装时，安装程序会在浏览器中保留进度，在执行其他操作之前先检查中断所在的步骤，再从该处继续，而不是从头开始。通过网络安装时，使用相同地址重新添加面板，会让 Home Assistant 在更改任何内容前再次检查面板；如果面板应用已经安装，Home Assistant 会将其连接，不会安装任何内容。

如果 Home Assistant 无法确定安装进行到了哪一步，它会停止，而不是猜测，并在消息中明确说明。[故障排查](/zh-hans/manage/troubleshooting/#网络安装中途停止)解释了各条消息以及接下来该怎么做。

## 每次更新前先备份

Panel Assistant 会在每次更新前备份面板设置，并为每台面板保留最近五份备份。更新后，它会确认面板已恢复正常运行。

在进行不确定的更改之前，以及每次移除应用或清除应用数据之前，请自行创建完整备份：在面板的网页界面中打开 **安装**，然后选择 **备份**，并检查下载的 `.hpb` 文件不为空。备份包含设置、持久面板状态、配置文件目录，以及由独立仪表盘应用保存且符合条件的登录信息。已学习的实体目录、接近感应历史和环境光历史会重新学习，而不会从备份恢复。在同一页面通过 **安装**，然后选择 **恢复** 来恢复备份。

## Panel Assistant 不会改动什么

Panel Assistant 不会为面板重新刷机或获取 root 权限，也绝不会改动面板固件。在部分已 root 的面板上，固件级备份和恢复属于另一项手动操作，详见[固件备份与恢复](/zh-hans/hardware/guides/firmware-backup-and-restore/)。[更新与恢复](/zh-hans/manage/updates-and-recovery/)介绍了出问题时可以恢复哪些内容。
