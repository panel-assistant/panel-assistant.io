带麦克风的面板可以充当 Home Assistant [Assist 卫星设备](https://www.home-assistant.io/voice_control/)。它监听唤醒词，将您的命令以音频流发送给 Home Assistant，再通过面板扬声器朗读回答。无需添加单独设备：卫星是面板现有 Home Assistant 设备上的 `assist_satellite.<panel>` 实体，音频通过面板已经使用的同一连接传输。

:::note
当设备配置文件声明有麦克风，或配置文件未指定而 Android 报告面板有内置麦克风时，会提供语音卡片。未经验证的麦克风必须通过面板的采集检查才能开始监听。如果配置文件明确声明没有麦克风，则不会提供语音功能。
:::

## 开启语音

新安装时，如果面板的设备配置文件声明有麦克风，语音默认开启。现有已保存的设置会保留。对于其他提供语音卡片的面板，请开启 **语音助手** 来使用。如果不希望面板监听唤醒词，请将其关闭。

1. 在 Home Assistant 的面板设备页面选择 **访问**，然后打开 **配置**（使用默认端口时，例如 `http://<panel>:8888/`）。
2. 在 **语音** 卡片上开启 **语音助手**。
3. 在 **唤醒词** 下勾选希望面板监听的各个唤醒词。
4. 在 **唤醒词流水线** 下，为每个勾选的唤醒词选择要使用的 Assist 管线。

关闭语音助手后，会释放其麦克风使用权，卫星实体在 Home Assistant 中显示为不可用。其他已启用的功能（例如相机房间音频）仍可能使用麦克风。

## 唤醒词和管线

面板内置四个唤醒词：**Okay Nabu**、**Hey Jarvis**、**Hey Mycroft** 和 **Alexa**。可以同时激活多个，每个都可以指向不同的 Assist 管线，因此不同唤醒词可以使用不同语言回答，或交给不同的对话代理。将唤醒词保持为默认设置时，会使用 Home Assistant 当前首选的管线。如果后来删除了为唤醒词分配的管线，该唤醒词也会回退到首选管线。

也可以直接从 Home Assistant 更改启用的唤醒词：在 **设置 > 语音助手** 或面板设备页面中，卫星自身的设置会显示同一列表，并将更改写回面板。每个唤醒词使用哪条管线，则在面板的配置页面上设置。

唤醒词检测在面板本地运行，不在云端或 Home Assistant 服务器上运行。面板只有在听到唤醒词后才开始向 Home Assistant 发送音频，而且仅在语音转文字仍接收命令期间发送；Home Assistant 报告命令结束后，立即停止发送。

想使用列表以外的唤醒词？参阅[自定义唤醒词](/zh-hans/manage/custom-wake-words/)。

## 面板上的提示

面板听到唤醒词时，会发出短促提示音并显示涟漪效果。在监听、思考或回答期间，屏幕边缘会显示柔和、缓慢脉动的色彩。颜色用于区分正在回答的管线：首次有面板使用某条管线时，Panel Assistant 会为其分配颜色并保留这一对应关系，因此同一管线在全屋面板上都显示相同颜色。无需配置。

如果管线的对话代理提出后续问题，面板会自行重新开始监听，无需再次说出唤醒词。

## 播报和发起对话

开启语音助手后，任何自动化或脚本均可使用 `assist_satellite.announce` 在面板上朗读消息，并可选择先播放短促提示音。`assist_satellite.start_conversation` 会朗读提示，然后监听回复；Home Assistant 仅允许支持主动发起对话的对话代理使用此功能，内置 Home Assistant 代理不支持。两个服务均需要开启语音助手；对于没有麦克风的面板，更简单的 REST 替代方式请参阅[文字转语音](/zh-hans/manage/text-to-speech/#play-an-announcement-with-the-voice-assistant-on)。

## 同一房间内的多个助手

如果同一 Home Assistant 实例上的两个卫星在相隔两秒以内听到同一个唤醒短语，Home Assistant 会抑制重复响应，让其中一个回答。这适用于该 Home Assistant 实例上的所有卫星，不仅限于同一 Home Assistant 区域中的面板，因此也包括面板与您已有的其他卫星。如果希望在同一房间中指定哪个设备回答，请给它们设置不同的唤醒词。

## 设置

除了唤醒词列表，语音卡片还提供几个调优选项：

- **唤醒灵敏度：** 低、正常或高。高会降低唤醒词模型的阈值，让面板更容易唤醒，但也更容易误触发；低要求更明确的匹配才会唤醒。
- **麦克风增益（dB）：** 仅放大送往 Home Assistant 进行转录的音频，绝不会放大唤醒词监听器自身分析的音频。如果唤醒词可靠触发，但从房间另一端说出的命令被漏掉或听错，请提高此值。
- **音频源：** 用于采集麦克风的 Android 音频源。除非得到其他指示，请保留默认值（`voice_recognition`）。

## 故障排查

**面板从不唤醒。** 确认 **语音助手** 已开启，且您说出的唤醒词已在 **唤醒词** 下勾选。尝试将 **唤醒灵敏度** 设为 **高**，并在平时使用面板的位置说话，而不是紧贴麦克风。

**能唤醒但无法理解命令。** 稍微提高 **麦克风增益（dB）** 后重试；这仅影响送去转录的音频，不会让面板本身更容易唤醒。如果您正在训练自己的唤醒词，面板日志还会记录近阈值事件及其分数，这是判断漏掉的唤醒词是差一点触发还是相差很远的最直接方式。参阅[自定义唤醒词](/zh-hans/manage/custom-wake-words/#测试与调优)。

**卫星实体显示不可用。** 语音助手已关闭，或面板未通过 Panel Assistant 连接到 Home Assistant。请从面板的配置页面开启语音助手；无法从 Home Assistant 开启。
