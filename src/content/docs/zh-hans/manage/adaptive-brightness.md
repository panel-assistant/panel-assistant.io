自适应亮度是面板上的一个可选控制器，可学习周围环境光的正常变化规律，并调节屏幕亮度，无需 Home Assistant 自动化。它默认关闭，无论开启还是关闭，都可以照常手动或通过 Home Assistant 控制亮度。

![面板网页界面的“设置”选项卡，其中“显示”卡片展示了环境光源、自动亮度、最低亮度、灵敏度以及每日环境光学习图表](/screenshots/ui-configure-dark.png)

## 选择光照源

打开**设置**，然后打开**显示**，选择**环境光源**：

- 如果当前启用的硬件配置文件和面板的实时能力检查均表明有可用的内置光线传感器，将此项留空即可使用该传感器。
- 如果面板自身没有合适的传感器，或者房间其他位置的传感器更能反映人们实际看到的光照情况，请选择一个 Home Assistant 照度实体。

使用 Home Assistant 光照源时，会通过仅针对该实体的单一订阅读取数据，而非读取完整的状态流。如果两种光照源都不可用，面板应用会保持自适应控制不可用，而不会根据一天中的时间来猜测光照。

当光照源为 Home Assistant 照度实体时，面板可以使用该实体最多七天的已有历史记录来初始化所学习的规律。这能为自动亮度提供一个有用的起点，无需等待新的读数逐渐积累。为此，该实体必须有历史记录，且 Home Assistant 历史记录服务必须可用；如果未返回可用的历史记录，学习就直接从新读数开始。

## 开启并调节

在同一张“显示”卡片中开启**自动亮度**。控制器会在面板上保留最多七天的环境光历史记录，并学习一天中各个时段的正常规律。短暂超出该规律的光照增强，例如打开房间里的灯，可以使建议亮度高于基线。

**最低亮度**设置自动控制会建议的最低亮度，并将学习到的范围重新缩放到**最低亮度**和**最高亮度**之间。其取值范围为 4% 到 99%。4% 的下限对应背光自身的最低亮度（背光永不熄灭），因此设置得更低只会移动控件，而不会改变屏幕亮度。它不限制手动亮度，手动亮度仍可设置得更低。

**最高亮度**限定自动亮度的上限，取值范围为 5% 到 100%，且须高于所选的最低亮度。它不限制手动亮度。

**灵敏度**决定控制器确认与所学规律的偏差确实存在后，将多大比例的偏差应用到屏幕亮度上。设为 0% 时，它会忽略偏差，仅使用所学规律。较低的值会使响应更平稳，默认值 50% 则为向上或向下调节留出相同的空间。它并非直接跟随光照变化的控制：短暂的光照增强只有在持续了一段时间，或上升幅度足够大、可被视为有效变化时，才会触发调节；而在仍在学习每日规律期间，无论此项如何设置，屏幕亮度都会跟随测得的光照。

七天图表可在控制器启用前或运行期间，预览观测范围、学习到的基线和建议亮度。对最低亮度、最高亮度和灵敏度所做的未保存更改会显示在预览中，但不会改写已存储的历史记录。

历史记录归属于所选光照源，以及根据 Home Assistant 的位置和时区得出的粗略房间与时间环境。位置、时区或光照源发生实质性变化时，会开始一份独立的历史记录，而不会悄然套用在另一环境中学到的规律。

## 手动更改与恢复

手动更改亮度会记录一个持续四小时的临时偏好，以免控制器立即与更改亮度的人相抗衡。自动调节起初的影响权重为 20%，并在四小时内随着临时偏好平滑淡出，逐步恢复完全控制。选择**恢复全自动**可立即结束该偏好，无需等待淡出完成。

移动面板、更换光照源后，或最近一周的情况已无法反映房间光照时，请选择**重置学习历史**。确认后，它会删除当前光照源和环境下的七天环境光历史记录，并重新开始学习。它不会更改所选光照源或自动亮度设置。

自适应亮度使用 Android 的常规屏幕亮度设置，不需要 root 权限。读取特定面板的光线传感器，仍可能取决于在该硬件上访问传感器的方式；具体由当前启用的配置文件和实时能力检查决定。

## Home Assistant 控制

如果面板提供了 `switch.<panel>_auto_brightness`，即可用它开启和关闭同一个控制器。屏幕亮度仍由 `light.<panel>_screen` 控制，因此从 Home Assistant 更改亮度会产生与在面板上更改亮度相同的临时偏好。在“设置”页面使用**恢复全自动**，即可直接恢复到学习得到的亮度。
