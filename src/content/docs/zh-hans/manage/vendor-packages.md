固件更新可能在面板上留下开机自行启动的厂商应用，并在仪表盘上覆盖悬浮组件。例如，Sonoff NSPanel Pro 120 的一次固件更新让 `com.eWeLinkControlPanel` 在开机时启动，并在面板显示的任何内容上覆盖控制组件。面板应用可以限制这类软件包，但仅限您指定的软件包。

## 工作方式

对于每个受限制的软件包，面板应用会执行三项可逆的特权操作，并在每次启动时重复执行：

| 步骤         | 机制                                        | 效果                                                    |
| ------------ | ------------------------------------------- | ------------------------------------------------------- |
| 强制停止     | `am force-stop <pkg>`                       | 立即停止应用，使其组件立即消失。                        |
| 禁止开机重启 | `pm disable-user --user 0 <pkg>`            | 阻止下次启动时再次运行。可通过 `pm enable <pkg>` 撤销。 |
| 阻止悬浮窗   | `appops set <pkg> SYSTEM_ALERT_WINDOW deny` | 移除其在仪表盘上绘制悬浮窗口的权限。                    |

三项操作均需要特权，因此该功能需要 **root 或 [root 辅助程序](https://github.com/panel-assistant/android/blob/main/helper/README.md)**。这意味着它也适用于将 root 限制在沙盒中的面板，例如 [Tuya TPA10](/zh-hans/hardware/panels/tuya/tpa10/)，此时操作通过辅助程序的 `STOP`、`DISABLE` 和 `OVERLAY` 命令执行。

## 使用方法

此功能在**面板自身网页界面的“安装”选项卡**中管理，而不是从 Home Assistant 管理。这是在设置面板或固件更新后进行的一次性操作，不是日常切换的功能，因此不放在仪表盘中。

在 Home Assistant 的面板设备页面选择 **访问**，打开 **安装**，找到 **厂商软件包** 卡片（例如使用默认端口时为 `http://<panel-ip>:8888/install`）。

按 **查找软件包…**，打开面板上可能需要控制的应用列表。列表分组显示，便于选择：

- **针对此面板的建议**：已知会干扰您硬件的固件应用，是优先选择的安全对象。在具备已知硬件配置文件的面板（例如 NSPanel Pro）上，`com.eWeLinkControlPanel` 会列在这里。每项都带有**标签**（例如 `vendor` 表示面板厂商应用，`chipset` 表示芯片厂商的工厂和测试应用，以及 `overlay`、`boot`），还有配置文件作者编写的简短**说明**，介绍它是什么以及为何被标记，便于区分 Sonoff 悬浮窗应用和固件镜像中遗留的无害 Rockchip 测试应用。
- **其他应用**：面板上不属于 Android 核心部分的应用。对于没有已知配置文件的面板，可在此查找具有启动器入口或悬浮窗权限的厂商附加应用。如果某个软件包未列出，可以直接输入其名称。
- **CPU 占用最高**：当前 CPU 使用量最高的应用。只限制您认识的应用。

每项都有 **停用** 按钮；如果知道软件包名称，也可以直接在输入框中输入。**停用** 会立即生效，无需另行保存，并会在每次启动时重新应用。已限制或已禁用的软件包会改为显示 **重新启用**，用于撤销操作。卡片本身仅列出您已限制的软件包，并显示各自状态：`active`、`disabled` 或 `not installed`。

按下“停用”按钮之前不会限制任何软件包。没有 root 或辅助程序时，卡片仍然可见，但处于锁定状态，并说明缺少的访问权限。

## 安全性

- **可逆。** 可通过 `pm enable <pkg>` 撤销禁用，应用或固件更新也可能将其撤销。这里没有破坏性操作：不会卸载，也不会清除数据。
- **拒绝操作关键软件包。** 面板应用绝不会停止或禁用系统界面、设置、电话服务、Android 框架或自身，即使您指定了它们。应用和特权辅助程序均执行此保护，因此拼写错误不会使面板变砖。
- **只操作您指定的已安装软件包。** 将由面板应用管理的软件包从期望列表中移除，会重新启用它并恢复已保存的悬浮窗权限。**重新启用** 也会撤销限制。

:::caution
您正在选择要禁用的软件包，因此请仅选择认识的厂商软件。禁用面板依赖的组件（例如您实际使用的厂商启动器或输入法），可能导致面板难以操作，直到通过 `adb` 重新启用。拿不准时，请保持原样。
:::
