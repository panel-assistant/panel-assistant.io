在桌面浏览器中设计的 Home Assistant 仪表盘，在 Android 壁挂面板上显示时，尺寸往往不正确：卡片过大，边缘被裁切，或者卡片过小。手机上的显示效果通常与桌面端大致一致，但面板却经常并非如此，因为厂商出厂时设置的系统密度和字体缩放比例与实际屏幕不太匹配。面板应用提供了 **逻辑密度（dpi）** 和 **文字大小** 两个控件，依次进入 **安装**、**显示尺寸** 即可找到，用于让布局和文字重新与桌面端的显示效果一致。通常需要同时使用这两个控件。

:::caution[实验性功能]
这些控件可以使用，但各面板的合适数值尚未确定。请将密度和文字大小视为需要尝试调整的设置，而非已经完善的功能。欢迎反馈在某台面板上效果良好的数值。
:::

## 使用方法

**显示尺寸** 卡片位于面板的 **安装** 选项卡中，可设置自定义逻辑密度和文字大小并实时应用，或将密度重置为 Android 的出厂基础密度。这两项设置在重启后都会保留，因为它们是 Android 系统设置。

:::note
这需要已获批准的特权途径：通常是厂商的 `su` 或 [root 辅助程序](https://github.com/panel-assistant/android/blob/main/helper/README.md)。如果兼容的非 root 面板已在面板上批准了可选的增强访问权限，也可以进行这些特定的显示调整。如果尚无可用的受支持途径，该卡片仍会显示，但保持锁定。
:::

调整时，请在桌面浏览器中打开同一个仪表盘作为参照。降低密度，直到布局匹配（能容纳更多卡片），然后微调文字大小，直到文字匹配。合适的数值不仅取决于型号，也取决于安装环境：面板的分辨率、人们站立的距离，以及仪表盘的设计方式。

部分受支持型号提供了推荐密度，其中大多数也提供推荐文字大小。Panel Assistant 设置这类没有特权途径的面板时，会通过 ADB 连接一次性应用这些值；通过 Panel Assistant 移除应用时，会恢复之前的值。

## 两个控件

| 控件                | 改变什么                                                                                                                                         | 机制                                 |
| ------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------ |
| **逻辑密度（dpi）** | 整个布局。以 dp 为单位的有效视口为 `physical px ÷ (density / 160)`。降低密度能容纳更多内容，更接近桌面浏览器较宽的视口；提高密度则会让内容更大。 | `wm density <n>`                     |
| **文字大小**        | 仪表盘中的文字。Android 的系统字体缩放会成为 WebView 的 `textZoom`（`textZoom = scale × 100`）。                                                 | `settings put system font_scale <f>` |

Android 的 `wm density` 输出将出厂基础值称为 `Physical density`。这一标签容易误导：它是清除覆盖值后 Android 用于布局的密度，并非对屏幕每英寸像素数的测量。面板应用将其报告为**出厂基础值**，并且只对屏幕尺寸已经独立核实的硬件配置文件显示实际 PPI。

仅调整密度会缩放布局，但文字大小可能仍与桌面不一致；字体缩放用于校正文字。结合调整两者，才能使面板与设计仪表盘时使用的浏览器显示效果一致。
