在桌面浏览器中设计的 Home Assistant 仪表盘，在 Android 壁挂面板上往往显示尺寸不对：卡片过大，边缘被裁切，或整体过小。手机通常与桌面显示效果大致一致，但面板经常不一致，因为厂商预设的系统密度和字体缩放比例与实际屏幕不太匹配。面板应用在**安装**中的**显示尺寸调整**提供了两个控件：**密度（DPI）** 和**文字大小（字体缩放）**，用于让布局和文字重新匹配。通常需要同时调整两者。

:::caution[实验性功能]
这些控件可以使用，但各面板的合适数值尚未确定。请将密度和文字大小视为需要尝试调整的设置，而非已经完善的功能。欢迎反馈在某台面板上效果良好的数值。
:::

## 使用方法

面板**安装**标签页中的**显示尺寸调整**卡片可以设置自定义逻辑密度和文字大小，并即时应用，也可以重置为 Android 的出厂基础密度。两项设置在重启后都会保留，因为它们属于 Android 系统设置。

:::note
这需要已获批准的特权途径：通常是厂商的 `su` 或 [root 辅助程序](https://github.com/panel-assistant/android/blob/main/helper/README.md)。如果兼容的非 root 面板已在面板上批准了可选的增强访问权限，也可以进行这些特定的显示调整。如果尚无可用的受支持途径，该卡片仍会显示，但保持锁定。
:::

调整时，请在桌面浏览器中打开同一个仪表盘作为参照。降低密度，直到布局匹配（能容纳更多卡片），然后微调文字大小，直到文字匹配。合适的数值取决于安装条件（面板分辨率、观看距离、仪表盘设计），而不是型号，因此应用不提供统一的标准数值。

## 两个控件

| 控件                     | 改变什么                                                                                                                                         | 机制                                 |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------ |
| **密度（DPI）**          | 整个布局。以 dp 为单位的有效视口为 `physical px ÷ (density / 160)`。降低密度能容纳更多内容，更接近桌面浏览器较宽的视口；提高密度则会让内容更大。 | `wm density <n>`                     |
| **文字大小（字体缩放）** | 仪表盘中的文字。Android 的系统字体缩放会成为 WebView 的 `textZoom`（`textZoom = scale × 100`）。                                                 | `settings put system font_scale <f>` |

Android 的 `wm density` 输出将出厂基础值称为 `Physical density`。这一标签容易误导：它是清除覆盖值后 Android 用于布局的密度，并非对屏幕每英寸像素数的测量。面板应用将其报告为**出厂基础值**，并且只对屏幕尺寸已经独立核实的硬件配置文件显示实际 PPI。

仅调整密度会缩放布局，但文字大小可能仍与桌面不一致；字体缩放用于校正文字。结合调整两者，才能使面板与设计仪表盘时使用的浏览器显示效果一致。
