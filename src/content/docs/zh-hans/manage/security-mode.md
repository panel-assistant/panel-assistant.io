面板的网页界面、API 和 Home Assistant 控制功能面向可信的家庭网络设计。默认使用**宽松模式**：自动化、安装工具和浏览器操作无需额外提示即可执行。有一项操作有意设为例外：通过 Home Assistant 实体开启摄像头，在包括宽松模式在内的所有模式下，都需要在面板上批准。“配置”中的摄像头设置是独立的所有者配置途径。关闭摄像头始终无需批准。

如果面板所在网络还有可信程度较低的设备，可选的**加固模式**会要求对某些影响较大的网络操作进行现场批准。这是额外的安全边界，不能替代单独的网络或防火墙，也不是 API 的通用身份认证。只读端点和面板常规控制仍可按正常的可信网络模型使用。

**在加固模式下，受保护的直接 LAN 请求需要在面板现场操作。只有在面板屏幕上有人批准后，请求才能执行，而且无法远程批准。**

使用已认证的 Panel Assistant 侧边栏的管理员，可以无需现场提示就执行某些常规管理操作：显示和电源配置、电源安全确认、配置文件激活、媒体播放、厂商软件包管控，以及仪表盘重载。安装、卸载、备份、恢复、重启和其他受保护操作仍需在面板上批准。直接 LAN 请求不享有这一例外。

网页界面在两种模式下都会用小盾牌标记相关操作，让你在开启加固模式之前就能看到哪些工作流程涉及批准边界。

## 开启加固模式

此设置只能在面板本机上更改：

1. 在面板上打开面板应用的**配置**界面。
2. 打开工具栏的更多菜单，选择**安全模式**。
3. 选择**启用加固模式**。

必须先关闭网络 ADB 和 Android 无线调试，因为其中任何一项都能让远程 ADB 客户端向批准界面注入输入。提交改动之前，面板应用会检查所有受支持的 Android 属性，核实网络 ADB、持久网络 ADB、显式 ADB 监听地址，以及无线调试的状态。它还会停止网络上任何正在运行的 WebView 开发者工具中继，并确认对应进程和监听器均已退出。如果无法确认这些远程控制途径已停用，应用会拒绝开启加固模式。请在 Android 开发者选项中关闭 ADB 和无线调试，然后重试。如果中继验证失败，请先重启面板，再重试。

此设置只属于面板本机。它不包含在配置导出或完整备份中，也无法通过 API、Home Assistant、恢复、导入配置，或对多台面板执行的更新来更改。因此，现有面板会保持宽松模式，除非有人在面板上开启加固模式。

使用同一菜单可以返回宽松模式。这样会清除所有待处理的批准请求。

## 批准网络请求

当加固模式拦截发往 API 的受保护请求时，首次尝试会返回 HTTP `202 Accepted`，并带有 `approval-required` 响应，例如：

```json
{
  "ok": false,
  "error": "approval-required",
  "approval_id": "…",
  "message": "Approve this request physically on the panel, then retry it; it cannot be approved remotely."
}
```

要完成该操作：

1. 在面板上依次打开**配置**、工具栏的更多菜单、**安全模式**，再选择**查看批准请求**。
2. 检查操作、操作摘要和发起请求的设备，然后批准或拒绝。
3. 在原始请求发出后的十分钟内，从同一设备再次发送完全相同的请求。

批准与操作、请求设备以及请求中的受保护内容绑定，且只能使用一次。更改请求、从其他地址发送、等待超过十分钟，或重启面板应用，都需要重新批准。只有匹配的重试才会消耗一次批准；它不是临时的通用绕过许可。

原生 Home Assistant 实体和自动化命令携带的是 Panel Assistant 的传输来源，而不是各个用户的身份。其批准与该来源和确切命令绑定。这与上文已认证管理员侧边栏的例外不同。

已在面板上运行的软件通过回环地址发出的请求无需网络批准。加固模式将本地 Android 应用视为可信，不会隔离面板上的不同应用，因此面板上不应有不可信应用。

## 受保护的操作

在加固模式下，直接网络客户端必须先在面板上获得批准，才能：

- 安装已上传的应用、受管理的面板应用副本或独立仪表盘应用；
- 卸载应用，或更改厂商软件包是否启用、是否运行，以及是否允许在屏幕上绘制覆盖层；
- 导出完整备份，或包含机密信息的配置包；
- 导入配置、恢复已保存的配置修订版本，或恢复面板备份；
- 激活或回滚硬件配置文件；
- 播放从远程 URL 获取的媒体；
- 重载仪表盘渲染器或重启面板；
- 从链接下载应用；下载与安装需要分别批准：下载与该确切 URL 的 SHA-256 绑定，获批前不会建立任何连接，因此在加固模式下从链接安装会请求两次批准；
- 推进数据库恢复维护；
- 修复独立仪表盘应用的配置，或清除内置渲染器的浏览数据；
- 更改系统显示密度或字体缩放比例；
- 通过配置页面或 Home Assistant 关闭已配置的保持唤醒或防止空闲调暗保护措施，这些措施用于保持面板可访问；
- 修复面板的电源安全设置；或
- 隐藏一条确切且未发生变化的提醒，该提醒涉及只能手动修复的电源安全设置。这只改变显示内容；底层评估、诊断信息和安装程序结果均保持不变。

通过 Home Assistant 实体开启面板摄像头，在两种模式下都需要在面板上批准。从配置页面开启仍是独立的所有者设置；依然需要 Android 摄像头权限和正常工作的摄像头使用中指示器。

在加固模式下远程保存配置时，降低电源安全保护的改动必须与厂商软件包改动分开保存，因为两者需要不同类型的批准。在宽松模式下，或通过回环地址，合并保存可以直接执行。

加固模式拒绝来自回环地址以外任何来源的点击注入，因此请求无法批准自身。它还会拒绝开启网络 ADB、Android 无线调试或 WebView 开发者工具中继。在使用其中任何一项前，请先在面板本机上将面板切回宽松模式。

批准边界不会让 8888 端口上 API 的其他部分具备身份认证。诊断和状态读取以及常规控制仍保持正常的可信网络行为。即使开启加固模式，也不要让不可信网络访问面板 API；[安全参考](/zh-hans/reference/security/)说明了完整的安全设计。

当你通过 Panel Assistant 安装，或自行选择安装时，更新才会开始。面板应用没有计划安装策略，也不保存更新通道。所有者仍可从**安装**标签页主动启动安装；在加固模式下，受保护的远程请求需要在面板上批准。

## 更改 Home Assistant 地址

更改 **Home Assistant URL** 会清除之前的登录凭据，除非在同一次保存中提供了新凭据。这适用于两种安全模式。普通保存若保持地址不变，并将机密字段留空，则会保留已存储的机密值。
