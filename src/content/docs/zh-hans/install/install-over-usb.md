USB 安装适用于尚未拆箱的面板，或厂商软件让网络访问变得困难的面板。将面板插到你正在使用的电脑上，浏览器即可通过线缆直接安装面板应用。面板不需要网络 ADB。浏览器必须始终连接到 Home Assistant，由它提供经过验证的发布版本。大多数人只会在面板上墙之前使用一次这种方式。

## 从 Home Assistant 中开始

USB 安装程序由管理员从 Home Assistant 启动：依次打开**设置**、**设备与服务**、**添加集成**，选择 **Panel Assistant**，再选择**在这台计算机上通过 USB 安装**。侧边栏中 Panel Assistant 页面上的**添加面板**链接也会打开同样的选项。Home Assistant 会检查发布版本，然后将其交给安装程序，安装程序会在独立的安全窗口中打开。因此，本网站没有安装按钮：执行安装的页面只接受来自你自己的 Home Assistant 的发布版本，未经 Home Assistant 验证的内容不会被安装到面板上。

## 你需要准备什么

- 已安装的 [集成](/zh-hans/home-assistant/custom-integration/)，以及管理员账户。
- 基于 Chromium 的浏览器，例如 Chrome 或 Edge。Firefox 和 Safari 无法与 USB 设备通信。
- 一根 USB 数据线，用来连接面板和运行该浏览器的电脑或手机，而不是连接 Home Assistant 服务器。
- 在面板的开发者选项中开启 USB 调试。如果连接时面板显示授权提示，需要有人在面板上接受；有些面板从不询问。[硬件页面](/zh-hans/hardware/)介绍了各型号如何进入开发者选项。

## 安装过程

1. 选择**打开 USB 安装程序**。在打开的页面中保留推荐版本，并按下**继续**。Home Assistant 会提供它能够验证的最新兼容版本。测试版本会标明，并在当前运行的集成允许时提供。
2. 安装程序在新窗口中打开并验证发布版本。按下 **查找我的面板**，并从浏览器列表中选择面板。
3. 如果面板要求允许 USB 调试，请勾选**始终允许使用这台计算机进行调试**，并在面板屏幕上批准。有些面板不会询问，安装程序会直接继续。
4. 确认安装。在你确认之前，面板上不会有任何改动。安装程序会拒绝覆盖不同的现有安装；如果已安装的正是所选构建版本，它会完成该构建版本的设置。
5. 保持数据线和窗口连接，直到安装程序报告完成。同一个窗口随后会进入面板的设置向导，由你完成设置。向导由面板提供，因此计算机需要与面板位于同一网络。

如果数据线中途断开，请重新插好，等待面板启动，按下安装程序错误页面上的按钮，然后按 **查找我的面板**。如果安装程序窗口已关闭，请从 Home Assistant 重新开始，并选择同一版本。无论哪种情况，安装程序都会在浏览器中保存进度，先检查所有中断的步骤，再进行其他操作，并从中断处继续，而不是从头开始。

## 安装完成后

面板已运行应用。刚拆箱的面板尚未接入你的网络，因此请在安装之前或之后，使用面板自身的设置应用将它连接到 Wi-Fi：设置向导和与 Home Assistant 的连接都需要网络。如果面板完成设置后仍未出现在 Home Assistant 中，请依次打开**设置**、**设备与服务**、**添加集成**，选择 **Panel Assistant**，再选择**添加网络中的面板**，并输入面板地址。USB 安装程序不会更新已安装应用的面板；更新方法请参阅 [更新与恢复](/zh-hans/manage/updates-and-recovery/)。
