USB 安装适用于尚未拆箱的面板，或厂商软件让网络访问变得困难的面板。将面板插到你正在使用的电脑上，浏览器即可通过线缆直接安装面板应用。面板不需要网络 ADB。浏览器必须始终连接到 Home Assistant，由它提供经过验证的发布版本。大多数人只会在面板上墙之前使用一次这种方式。

## 从 Home Assistant 中开始

管理员从 Home Assistant 侧边栏中的 Panel Assistant 页面打开 USB 安装程序。Home Assistant 会检查发布版本，然后将其交给安装程序，安装程序会在独立的安全窗口中打开。因此，本网站没有安装按钮：执行安装的页面只接受来自你自己的 Home Assistant 的发布版本，未经 Home Assistant 验证的内容不会被安装到面板上。

## 你需要准备什么

- 已安装的 [集成](/zh-hans/home-assistant/custom-integration/)，以及管理员账户。
- 基于 Chromium 的浏览器，例如 Chrome 或 Edge。Firefox 和 Safari 无法与 USB 设备通信。
- 一根 USB 数据线，用来连接面板和运行该浏览器的电脑或手机，而不是连接 Home Assistant 服务器。
- 在面板的开发者选项中开启 USB 调试，并安排一人在面板旁，在授权提示出现时确认授权。[硬件页面](/zh-hans/hardware/)介绍了各型号如何进入开发者选项。

## 安装过程

1. 在 Panel Assistant 页面选择版本。Home Assistant 会提供它能够验证的最新兼容版本。测试版本会标明，并在当前运行的集成允许时提供。
2. 安装程序窗口会验证发布版本，并要求你在浏览器的 USB 提示框中选择面板。
3. 在面板屏幕上确认 USB 调试授权提示。
4. 确认安装。在你确认之前，面板上不会有任何改动。安装程序会拒绝覆盖不同的现有安装；如果已安装的正是所选构建版本，它会完成该构建版本的设置。
5. 保持数据线连接，并让标签页保持连接，直到安装程序报告完成，然后在面板上完成引导式设置。

如果数据线中途断开或窗口中途关闭，请重新插好数据线，再次从 Home Assistant 传送同一发布版本，并重新连接同一面板。安装程序会在浏览器中保存进度，先检查所有中断的步骤，再进行其他操作，并从中断处继续，而不是从头开始。

## 安装完成后

面板已运行应用，安装程序会尝试自动将其添加到 Home Assistant。如果 Home Assistant 无法访问面板，请在面板接入 Home Assistant 所在的网络后添加。USB 安装程序不会更新已安装应用的面板；更新方法请参阅 [更新与恢复](/zh-hans/manage/updates-and-recovery/)。
