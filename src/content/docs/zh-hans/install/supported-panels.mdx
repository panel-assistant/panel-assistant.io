**Panel Assistant 可在搭载 Android 8.0 或更新版本且开放调试访问的 ARM 架构 Android 壁挂面板上运行。** 无需先在列表中找到对应型号：安装后，Home Assistant 仪表盘、屏幕亮度和息屏、音频以及面板的标准传感器就会立即接入 Home Assistant。

以下每个型号都有自己的[硬件页面](/zh-hans/hardware/)，列出了购买前需要核实的信息。如果有对应型号或系列的配置文件，就能支持该面板特有的硬件，例如 LED、按钮、继电器、摄像头、麦克风和环境传感器。

每个条形指示器都表示我们对该面板的信心程度，信心越高，填充越满，颜色也越绿。我们用自有实机检查过的面板最有把握，如果厂商固件还允许 Panel Assistant 访问面板，把握就更大。对于其他面板，信心来自对厂商固件的分析、制造商文档、与我们检查过的面板共用平台，以及在该面板上运行 Panel Assistant 的用户；而我们尚未检查过的较旧 Android 版本则会降低信心。将鼠标悬停在面板条目上或打开条目，即可查看它具备上述哪些依据。

其中有几款面板其实是以不同品牌销售的相同硬件。每个品牌的名称都会列出，并指向该硬件共用的同一个页面。

## 所有其他 Android 面板

**此处未列出名称的面板仍然受到支持。** Panel Assistant 无需识别硬件即可在其上运行。任何满足以下要求的面板都会以 Generic 配置文件启动，提供屏幕上的仪表盘、亮度和息屏、音频、导航，以及光线和距离等标准 Android 传感器；所有这些都会作为实体，归属于 Home Assistant 中该面板自身对应的设备。

型号专属配置文件增加的是对该型号特有硬件的支持。许多面板没有这类硬件，许多用户也从不需要这类支持。对他们而言，Generic 就是完整的功能集，并非功能缩水的版本。

## 面板需要满足的要求

- **ARM 架构上的 Android 8.0 或更新版本。** 已发布的构建版本支持 `arm64-v8a` 和 `armeabi-v7a`。
- **开发者选项。** 安装程序使用 Android 的调试接口，几乎所有面板都允许开启该接口。
- **任意系统 WebView。** 厂商出厂时搭载的浏览器引擎往往已经过时。面板应用会对其进行检查，[准备面板](/zh-hans/install/prepare-a-panel/)介绍了如何在面板上更新它。
- **root 权限，仅少数附加功能需要。** 某些型号上的部分功能需要 root 权限。各硬件页面会说明哪些功能需要，以及如何获取该权限。

## 还没列入列表？

硬件支持由数据定义，而非代码，因此添加面板意味着编写配置文件，而不是编写新版应用。要让自己的型号获得专属配置文件，最快的方式就是告诉我们有关情况：在 [issues](https://github.com/panel-assistant/android/issues) 中说明型号以及实际运行情况。如果想自行编写，[配置文件文档](/zh-hans/reference/profiles/)介绍了配置文件包含的内容。每一份报告，无论运行是否成功，都能让更多面板出现在此页面上。
