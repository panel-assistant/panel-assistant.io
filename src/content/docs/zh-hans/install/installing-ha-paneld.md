您可以直接在 Home Assistant 中添加面板，无需命令行。两种方式最终都会让面板作为设备显示。

无论选择哪种方式，都请先完成[准备面板](/zh-hans/install/prepare-a-panel/)中的步骤。

## 通过网络

适用于已连接到您网络的面板。前往 **设置**、**设备与服务**，添加 **Panel Assistant**，并输入面板地址。集成会检查面板上的内容，必要时请您在面板自己的屏幕上批准调试提示，再请您确认安装，安装面板应用并启动，最后才创建设备。如果面板已运行该应用，则会直接接管，速度更快。

## 通过 USB

适用于尚未使用的面板，或厂商软件使网络访问不便的面板。将其连接到笔记本电脑，在浏览器中通过 USB 线安装。浏览器始终连接到 Home Assistant，由它提供经过验证的发布版本；面板无需网络 ADB。通过 **设置**、**设备与服务**、**添加集成**、**Panel Assistant**、**在此计算机上使用 USB 安装** 启动；需要基于 Chromium 的浏览器。参阅[通过 USB 安装](/zh-hans/install/install-over-usb/)。

两种安装程序还可以在受支持的面板上请求安装经过验证且兼容的浏览器引擎更新。更新未能完成不会阻止设置或配对；恢复方法参阅[准备面板](/zh-hans/install/prepare-a-panel/)。

## 安装程序提供的保护

两种方式都会在更改任何内容之前检查面板。网络方式会接管现有应用，而不是重新安装。USB 不会覆盖已有的其他安装；如果已安装的正是所选构建版本，它会完成该构建版本的设置。中断的 USB 安装可以使用同一发布版本重试，继续之前会检查哪些步骤已经完成。应用更新前的备份请参阅[更新与恢复](/zh-hans/manage/updates-and-recovery/)。

## 安装后

面板会作为设备显示，提供状态传感器和诊断信息，并出现在侧边栏的 Panel Assistant 页面上。接下来，在面板自身的设置向导中完成设置，为面板命名并选择仪表盘。完成设置之前，面板屏幕会显示二维码和 **设置** 按钮，因此您也可以使用手机或直接在面板上完成。以后如需更改仪表盘，请打开 Home Assistant 中的面板设备页面，选择 **访问**。如果直接打开面板地址，请使用它报告的 HTTP 端口；默认值为 8888。

继续阅读[连接面板](/zh-hans/home-assistant/connect-a-panel/)。
