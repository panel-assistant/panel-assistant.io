添加面板前必须满足一个条件，另一个条件则决定首个仪表盘能否正常显示。具体途径取决于您的型号和固件。

## 1. 开启开发者选项和调试

安装程序通过 Android 的调试接口与面板通信。厂商可能禁用或限制此接口。在大多数面板上，打开 **设置**，进入 **关于**，连续点按 **版本号** 七次，直到面板提示您已成为开发者；此后 **开发者选项** 会出现在设置中。有些厂商会隐藏或重命名这些选项，[硬件页面](/zh-hans/hardware/)提供了已知步骤，并标明尚未验证的操作。在开发者选项中，为 [USB 方式](/zh-hans/install/install-over-usb/)开启 **USB 调试**，或为网络方式开启 **TCP 端口 5555 上的网络 ADB**。并非每款面板都有网络 ADB 开关；您型号的硬件页面会说明是否具备。如果没有，请在 USB 调试可用后使用 USB 方式。如果 USB 访问也尚未验证，请在选择任一安装程序之前，向供应商询问适用于您型号和固件的说明。root 权限是另一回事：`adb root` 命令以调试已经可用为前提。Android 通过配对使用的“无线调试”是另一种连接方式，此安装程序不支持。

如果面板要求授权连接，必须有人在面板自己的屏幕上接受该提示；无法远程接受。

面板无需固定地址：Panel Assistant 会跟随地址变化的面板。

## 2. 系统 WebView 已更新

仪表盘由面板的系统 WebView（也称浏览器引擎）绘制。旧版 WebView 可能导致仪表盘空白或显示不完整。

在尚未发布的 1.0.0-rc2 版本中，网络和 USB 安装程序均可在受支持的面板上请求安装经过验证且兼容的浏览器引擎更新。即使更新未能完成，仍可进行设置和配对。未完成的尝试可以从 Home Assistant 中的面板更新修复项继续：选择 **重试**。它会先检查已有进度，再请求再次尝试；更新失败后不会定时自动重试。

在该版本中，如果内置浏览器引擎过旧，设置向导会显示警告。您可以完成设置和配对，但仪表盘仍可能无法显示。如果面板无法安装更新，请按照[更新系统 WebView](/zh-hans/hardware/guides/update-the-webview/)中的说明操作。

## 在进行不可逆更改之前

Panel Assistant 本身不会刷写固件或获取 root 权限。某些面板可以手动获取 root 权限或刷写固件，其中有些操作可以恢复，有些则不能。如果您准备这样做，请先阅读[安装安全](/zh-hans/manage/install-safety/)；有关可以备份和无法备份的内容，请参阅[更新与恢复](/zh-hans/manage/updates-and-recovery/)。
