在 Home Assistant 中打开 **设置 → 系统 → 修复**，选择 Panel Assistant 消息。第一个链接会打开相关设置或恢复步骤。使用**了解更多**查看下方说明。

排查安装或更新失败时，请保留已保存的支持报告。**清除错误**操作会删除该报告；它不会更改面板。

检查报告和面板后，才可使用现有修复中的受保护**重试**操作。安装状态未知时，不要重新启动自动安装、卸载或重置。请参阅[安装恢复](/zh-hans/manage/troubleshooting/#网络安装中途停止)和[支持报告](/zh-hans/home-assistant/support-report/)。

## 从 &lt;面板&gt; 移除 Panel Assistant

**含义：** 在尚未发布的 1.0.0-rc2 版本中，有人在此面板的设备页面上按下了**从此面板移除**。此按钮不会移除任何内容；此修复会一直保持可用，直到移除完成。

**原因：**Panel Assistant 会在恢复厂商主屏幕和应用、卸载 ha-paneld 以及从 Home Assistant 中删除面板之前，请您确认。

**解决方法：** 请先阅读[移除会执行哪些操作以及如何重新安装](/zh-hans/manage/removal-risks/)，再选择一次**提交**以确认。如果这是误操作，请关闭对话框而不提交，让此修复保持未确认状态。

<a id="panel-app-too-old"></a>

## 面板应用过旧

**含义：**Home Assistant 无法通过当前连接协议查看或控制面板。

**原因：**面板应用未报告受支持的连接协议，或其协议范围与此 Panel Assistant 能提供的范围不重叠。

**解决方法：**打开 Home Assistant 更新，为此面板安装可用的兼容应用更新，然后等待重新连接。如果没有可用更新，请使用更新恢复指南；不要盲目降级。

<a id="old-app-needs-090"></a>

## 旧版应用需要 0.9.0

**含义：**Panel Assistant 1.0 无法为此旧版应用面板安装或更新。

**原因：**1.0 移除了从旧版 ha-paneld 应用迁移的功能。

**解决方法：**不要在运行中的 1.0 安装上重新下载 Panel Assistant 0.9.0：1.0 移除的一项设置可能导致 0.9.0 将已迁移面板恢复为 MQTT。只有在所有面板都尚未安装 1.0 应用时，才可恢复升级前的 Home Assistant 备份，在 0.9.0 中完成所有迁移，然后返回 1.0。如果已有任何面板安装了 1.0 应用，或没有合适的备份，请先寻求支持，再更改版本。请参阅 [1.0 升级恢复指南](/zh-hans/manage/upgrade-to-1-0/)。

<a id="mqtt-panel-needs-090"></a>

## MQTT 面板需要 0.9.0

**含义：**Panel Assistant 无法连接此尚未迁移的 MQTT 面板，否则会拆分其实体和历史记录。

**原因：**Panel Assistant 1.0 不再执行 MQTT 迁移。

**解决方法：**不要在运行中的 1.0 安装上重新下载 Panel Assistant 0.9.0：1.0 移除的一项设置可能导致 0.9.0 将已迁移面板恢复为 MQTT。只有在所有面板都尚未安装 1.0 应用时，才可恢复升级前的 Home Assistant 备份，在 0.9.0 中完成所有迁移，然后返回 1.0。如果已有任何面板安装了 1.0 应用，或没有合适的备份，请先寻求支持，再更改版本。请参阅 [1.0 升级恢复指南](/zh-hans/manage/upgrade-to-1-0/)。

<a id="panel-permissions"></a>

## 面板权限

**含义：**Android 尚未授予某些权限，因此部分面板功能无法工作。仪表盘仍可使用。

**原因：**旧版安装或 Android 权限变更可能使所需授权缺失。启用摄像头时需要摄像头权限；启用摄像头或语音时需要麦克风权限。功能状态未知时，警告会保留，直到能够检查。

**解决方法：**在面板实机上打开 Android 设置 → 应用 → Panel Assistant。允许列出的摄像头、麦克风和通知权限。在特殊应用权限下，允许修改系统设置和显示在其他应用上层，然后在无障碍功能中启用 Panel Assistant。如果导航设为滑动显示或始终显示，但缺少悬浮层权限，请从仪表盘底部向上滑动，打开展示在其他应用上层设置，允许后返回并再次滑动。返回修复并提交。Home Assistant 必须重新验证所有相关授权；读取失败或仅更新应用都不能关闭此修复。

<a id="panel-proximity-setup"></a>

## 面板接近感应设置

**含义：**面板尚未保存接近感应校准，因此无法使用挥手唤醒。

**原因：**面板报告 calibration_required。校准需要测量当前安装环境，并有人站在面板前；仅启动设置不代表已完成。

**解决方法：**打开此面板的设置页面，在存在与唤醒中选择在面板上设置接近传感器。按照面板上的实机提示操作，约需一分钟。显示校准已保存后，返回修复并提交。Home Assistant 会读取最新状态后才完成修复；如果设置仍在运行或无法读取面板，请完成设置或恢复连接后再次提交。仪表盘上的打开接近传感器设置操作也可从面板上启动此流程。

<a id="dashboard-unfiltered"></a>

## 仪表盘未过滤

**含义：**面板显示的仪表盘包含 Home Assistant 的所有实体，而非仅包含仪表盘使用的实体。

**原因：**面板学习仪表盘使用哪些实体时，会先显示说明等待原因的画面。如果等待超过 90 秒，面板会显示未过滤的仪表盘，以免您无法使用。常见原因包括 Home Assistant 未回应扫描、Home Assistant 拒绝登录、仪表盘规则需要您决定，以及浏览器引擎过旧而无法过滤。面板会在仪表盘后台继续尝试。

**解决方法：**在 Panel Assistant 侧边栏中打开此面板，然后打开实体，查看等待原因。在那里决定如何处理标记的规则；如果 Home Assistant 拒绝登录，请从设置重新登录。如果 Panel Assistant 提供更新的浏览器引擎，请安装。面板会自行恢复为过滤后的仪表盘，此修复也会清除。

<a id="voice-microphone-silent"></a>

## 语音麦克风静音

**含义：**麦克风采集检查只录到静音，因此面板没有监听唤醒词。

**原因：**检查只发现静音或不变的音频底噪。

**解决方法：**在 Panel Assistant 侧边栏中打开此面板，然后打开设置 → 语音助手。关闭后重新开启以再次运行检查。如果仍失败，请更改同一语音卡片中的音频源；直接链接会显示此高级设置。检查成功会清除此修复。关闭语音也会撤销它，因为不再请求监听。

<a id="voice-microphone-no-audio"></a>

## 语音麦克风无音频

**含义：**麦克风采集检查未收到音频，因此面板没有监听唤醒词。

**原因：**Android 音频采集未提供音频，也没有更具体的错误。

**解决方法：**在 Panel Assistant 侧边栏中打开此面板，然后打开设置 → 语音助手。关闭后重新开启以再次运行检查。如果仍失败，请更改同一语音卡片中的音频源；直接链接会显示此高级设置。检查成功会清除此修复。关闭语音也会撤销它，因为不再请求监听。

<a id="voice-microphone-no-audio-detail"></a>

## 语音麦克风无音频详情

**含义：**麦克风采集检查未收到音频，因此面板没有监听唤醒词。

**原因：**Android 音频采集未返回音频；面板报告的详情说明了采集错误。

**解决方法：**在 Panel Assistant 侧边栏中打开此面板，然后打开设置 → 语音助手。关闭后重新开启以再次运行检查。如果仍失败，请更改同一语音卡片中的音频源；直接链接会显示此高级设置。检查成功会清除此修复。关闭语音也会撤销它，因为不再请求监听。

<a id="wake-word-kept"></a>

## 保留了唤醒词

**含义：**此面板保留了共用唤醒词 ID 下自己的模型，因此没有使用共用模型。

**原因：**已安装模型的 SHA-256 与共用模型不同，也不是先前共用模型的副本。Panel Assistant 会保留独立导入的模型，而不会覆盖。

**解决方法：**在 Panel Assistant 中打开此面板，然后打开设置、唤醒词。如果希望在此使用共用模型，请在此面板导入匹配的 .json 清单和 .tflite 模型。如果这是有意保留的模型，请保持不变；自动共享绝不会替换它。通过侧边栏导入时，也会将导入的模型设为共用副本；共享不会激活唤醒词。

通过侧边栏导入会替换共用副本，并可能更新其他面板。请参阅[自定义唤醒词](/zh-hans/manage/custom-wake-words/)。

<a id="wake-word-refused"></a>

## 拒绝了唤醒词

**含义：**共用唤醒词未安装到此面板；其他已安装唤醒词仍可用。

**原因：**面板拒绝了导入的模型，并报告原因。模型可能有无效清单、超出限制、无法通过唤醒词引擎检查或保存失败。一台面板接受的模型可能被另一台拒绝。

**解决方法：**在 Panel Assistant 中打开此面板，然后打开设置、唤醒词。根据报告原因修正或重新训练 microWakeWord 模型，再在那里导入匹配的 .json 清单和 .tflite 文件。导入时会显示面板响应，被拒绝时保留上一个可用模型。共享不会激活唤醒词；如果希望面板监听它，请选中它。不受支持的旧版应用命令和连接超时会产生警告，而非此修复。

通过侧边栏导入会替换共用副本，并可能更新其他面板。请参阅[自定义唤醒词](/zh-hans/manage/custom-wake-words/)。

<a id="volume-number-removed"></a>

## 音量数值实体已移除

**含义：**自动化或脚本仍引用已从面板移除的独立音量数值实体，而该面板现已具有媒体播放器。这些操作需要更新。

**原因：**面板媒体播放器现在负责音量。Home Assistant 启动后，Panel Assistant 只移除该面板原来的音量数值实体，并列出仍引用它的自动化和脚本。

**解决方法：**打开自动化或脚本，找到修复中列出的项目。将以已移除数值实体为目标的 number.set_value 操作替换为以面板媒体播放器为目标的 media_player.volume_set；将 volume_level 设为 0 到 1，例如 0.5 表示 50%。根据其他引用的用途更新它们。保存并检查自动化或脚本可正常工作后，忽略此修复。Panel Assistant 不会自动重写它们。

<a id="restart-required"></a>

## 需要重启

**含义：**Home Assistant 仍在运行先前版本的 Panel Assistant。

**原因：**已安装集成的版本/构建与 Home Assistant 已加载的代码不同。

**解决方法：**打开修复，检查已安装与运行中的版本，准备好重启 Home Assistant 并加载已安装版本后，选择提交。

<a id="panel-user-mismatch"></a>

## 面板用户不匹配

**含义：**一个面板账户请求正在等待您的确认。

**原因：**已登录的 Home Assistant 用户请求以此面板身份连接。首次绑定或更改已保存账户需要您的批准。

**解决方法：**打开修复，将列出的面板和用户与您有意设置的账户进行比较。只有认识此请求时才选择提交。如果面板已有不同账户，确认变更后将停止接受该账户。如果请求出乎意料，请关闭对话框并忽略问题：任何已登录用户都可以请求面板连接。

<a id="no-update-route"></a>

## 没有更新途径

**含义：**Panel Assistant 无法安装应用更新；面板保留当前应用版本，其他功能仍正常工作。

**原因：**面板不再提供可用的更新途径，可能发生在固件变更或重置后。

**解决方法：**按照[无法更新面板的指南](/zh-hans/manage/updates-and-recovery/#无法更新的面板)操作。恢复方式取决于型号和固件：仅在指南要求时恢复调试访问或重新通过 USB 连接。Home Assistant 获得可用更新途径后，此修复会清除。

<a id="merged-panel-identity"></a>

## 面板身份已合并

**含义：**多个条目声明同一身份，因而无法安全确定原生连接的归属。

**原因：**克隆的标识符或历史共用标识符使会话归属不明确；集成拒绝选择面板。

**解决方法：**更新所有受影响面板实机上的应用，使每台都报告自己的身份。然后在 Home Assistant 删除已合并的设备，让面板重新注册。检查先前版本禁用的实体；它们不会自动恢复。

<a id="installer-failure"></a>

## 安装程序失败

**含义：**安装或更新未完成。

**原因：**失败不符合更具体的修复原因。

**解决方法：**打开其支持报告查看情况，解决报告的原因后使用重试。

<a id="installer-failure-authorization-failed"></a>

## 安装程序失败：授权失败

**含义：**安装无法连接到面板上的 Android。

**原因：**面板未接受 Home Assistant 的 ADB 连接。

**解决方法：**按照准备面板指南检查面板调试和批准提示，然后在修复中使用重试。

<a id="installer-failure-preflight-rejected"></a>

## 安装程序失败：预检拒绝

**含义：**请求的应用未安装。

**原因：**安装程序在安装前的检查中拒绝了面板。

**解决方法：**打开支持报告，修正报告的检查问题；如果面板和所选发布版本仍匹配，再使用重试。

<a id="installer-failure-artifact-rejected"></a>

## 安装程序失败：安装包拒绝

**含义：**请求的应用未安装。

**原因：**发布版本无法通过身份验证，或本地暂存检查失败，包括暂存路径不安全或已被占用。

**解决方法：**打开支持报告，找出被拒绝的发布版本或暂存检查，解决原因后通过修复重试。

<a id="installer-failure-transport-failed"></a>

## 安装程序失败：传输失败

**含义：**Home Assistant 无法完成应用传输或安装。

**原因：**传输操作失败；可能是连接问题，也可能是传输或安装操作被拒绝。

**解决方法：**恢复面板连接，然后在修复中使用重试，让 Panel Assistant 在继续前检查其当前状态。

<a id="installer-failure-install-failed"></a>

## 安装程序失败：安装失败

**含义：**Android 拒绝了请求的安装。

**原因：**面板的软件包安装失败；支持报告包含结果。

**解决方法：**阅读支持报告并解决其中的 Android 错误，然后在修复中使用重试。

<a id="installer-failure-launch-failed"></a>

## 安装程序失败：启动失败

**含义：**应用已安装，但未启动。

**原因：**安装程序无法在安装后启动 Panel Assistant。

**解决方法：**从面板应用列表打开 Panel Assistant，然后在修复中使用重试来检查并完成此次尝试。如果无法打开，请使用支持报告寻求帮助。

<a id="installer-failure-health-check-failed"></a>

## 安装程序失败：健康检查失败

**含义：**应用已启动，但尚未确认健康状态。

**原因：**安装程序未收到所需的健康响应。

**解决方法：**检查面板上的应用，然后在修复中使用重试检查状态。如果仍不健康，请使用支持报告寻求帮助。

<a id="installer-failure-ambiguous-mutation"></a>

## 安装程序失败：更改状态不明确

**含义：**Panel Assistant 无法判断失败的尝试是否更改了面板。

**原因：**安装结果未能证明面板最终的软件包状态。

**解决方法：**检查面板实机上安装了什么，并打开修复的支持报告。只有检查报告状态后，才使用受保护的重试操作；不要为了清除消息而卸载、清除应用数据或重置面板。

<a id="installer-failure-verification-required"></a>

## 安装程序失败：需要验证

**含义：**在能够检查面板之前，将暂停其他安装。

**原因：**先前尝试需要先验证，才能继续安装。

**解决方法：**检查面板及其支持报告，然后在修复中使用重试，重新检查当前状态。不要为了清除消息而卸载、清除应用数据或重置面板。

<a id="installer-failure-update"></a>

## 安装程序失败：更新

**含义：**Home Assistant 无法确认更新已完成。在尚未发布的 1.0.0-rc2 版本中，面板应用可能已经安装，但浏览器引擎更新仍未完成。

**原因：**应用更新，或该版本中的浏览器引擎更新失败或无法验证。修复会保留整个尝试的报告。

**解决方法：**阅读支持报告，恢复报告中要求的连接或安装条件，然后选择**重试**。在尚未发布的 1.0.0-rc2 版本中，如果仅浏览器引擎更新未完成，且 Panel Assistant 确认请求的应用版本已安装，它会继续该阶段而不重新安装应用。如果提供**允许更新**，请先用它在面板上批准 Home Assistant。如果浏览器引擎无法更新，请参阅 [WebView 指南](/zh-hans/hardware/guides/update-the-webview/)。

<a id="installer-failure-retry-hold"></a>

## 安装程序失败：重试暂停

**含义：**重试已暂停，尚未获准继续。

**原因：**安全检查或意外重试错误停止了此次尝试。已保存的报告记录观察结果；暂停不代表获准重新安装。

**解决方法：**阅读报告的重试错误和支持报告，检查目标面板与发布版本仍然匹配，解决原因后再使用重试。清除错误只会删除修复及其保存的报告。

<a id="panel-address-unreachable"></a>

## 面板地址无法访问

**含义：**通过实时连接仍可控制面板，但 HTTP 操作没有已验证可访问的地址。

**原因：**已存地址不再响应；自动恢复没有可用候选地址或无法验证候选地址。

**解决方法：**恢复面板网络/HTTP 可访问性，或使用当前地址添加同一面板；不要绕过身份检查。

<a id="panel-address-unverified"></a>

## 面板地址未验证

**含义：**通过实时连接仍可控制面板，但 HTTP 操作没有已验证可访问的地址。

**原因：**已存地址不再响应；自动恢复没有可用候选地址或无法验证候选地址。

**解决方法：**恢复面板网络/HTTP 可访问性，或使用当前地址添加同一面板；不要绕过身份检查。

<a id="panel-identity-mismatch"></a>

## 面板身份不匹配

**含义：**身份不同的端点会被拒绝提供面板状态和控制。

**原因：**某个地址现在响应为另一个安装，或无法安全协调已保存的身份证据。

**解决方法：**检查面板实机和地址；如果已迁移，请重新添加当前已知面板。绝不要仅因不同身份使用旧地址就批准它。

<a id="panel-link-shared"></a>

## 面板链接共用

**含义：**重新安装的面板无法安全地归属于某个现有设置。

**原因：**多个条目记录了相同的旧版设备链接；问题不在地址可访问性。

**解决方法：**保留在线的其他面板；只移除未使用条目，或单独添加重新安装的面板。

<a id="panel-identity-confirmation"></a>

## 面板身份确认

**含义：**面板报告新的设备身份后，现有面板设置正在等待您的确认。

**原因：**Panel Assistant 无法自动证明各新身份属于先前的设置。

**解决方法：**检查列表中每个面板名称和地址。只有每个列出的面板都属于其现有设置时才选择提交。打开对话框不会更改任何内容。

<a id="installer-failure-adb-authorization"></a>

## 安装程序失败：ADB 授权

**含义：**此面板允许 Home Assistant 之前，失败的更新无法继续。

**原因：**仍需批准 ADB 信任；失败更新的报告仍可查看。

**解决方法：**在修复中选择允许更新并提交，然后在指定面板上勾选始终允许使用这台计算机进行调试并点击允许。返回修复，为失败的更新使用重试。

<a id="adb-update-authorization"></a>

## ADB 更新授权

**含义：**面板允许之前，Home Assistant 无法使用 ADB 更新此面板。

**原因：**更新途径要求在面板上明确批准信任。

**解决方法：**打开修复并提交，然后在指定面板上勾选始终允许使用这台计算机进行调试并点击允许。Android 可能将 Home Assistant 称为计算机；批准后流程会继续。

<a id="another-home-assistant"></a>

## 另一个 Home Assistant

**含义：**在这里添加面板不会更改其已保存的服务器或账户。

**原因：**面板保存的 Home Assistant 地址指向另一台服务器。

**解决方法：**如果希望此面板连接这里，请按照修复链接打开设置，输入此 Home Assistant 地址，保存，然后重新连接并使用希望面板使用的账户登录。如果它应连接另一台服务器，请保持设置不变并忽略此修复。如果侧边栏无法访问它，请在面板所在网络直接打开设置。
