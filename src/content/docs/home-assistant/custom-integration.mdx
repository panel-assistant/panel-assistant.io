Panel Assistant is a custom integration. You need Home Assistant **2026.8.3 or newer**. On **2026.11 or newer**, use the built-in [Marketplace](https://www.home-assistant.io/integrations/marketplace/). On **2026.8.3 through 2026.10**, use [HACS](https://hacs.xyz/).

<LinkButton
  href="https://my.home-assistant.io/redirect/hacs_repository/?owner=panel-assistant&repository=ha-integration&category=integration"
  icon="external"
>
  Open in Marketplace or HACS
</LinkButton>

This button opens the repository in Marketplace on Home Assistant 2026.11 or newer, or HACS on supported older versions. It opens the download page; you still need to install the integration and add Panel Assistant afterwards.

## Home Assistant 2026.11 or newer: Marketplace

1. Sign in as an administrator and open **Settings**, **Marketplace**. Accept its warning when asked, and connect your GitHub account if Marketplace asks you to.
2. Search for **Panel Assistant** and open it, or use the button above.
3. Choose **Install**, review the version, and confirm **Install**.
4. Follow the setup prompt after installation. If Marketplace asks for a Home Assistant restart, complete it first. You can also open **Settings**, **Devices and services**, **Add integration**, and choose **Panel Assistant**.

If you used HACS before upgrading Home Assistant to 2026.11, Marketplace keeps your installed repositories and custom repositories. You do not need to remove and reinstall Panel Assistant for that change.

## Home Assistant 2026.8.3 through 2026.10: HACS

1. Install [HACS](https://hacs.xyz/docs/use/) if you do not already have it.
2. In HACS, search for **Panel Assistant** and open it, or use the button above.
3. Download **Panel Assistant**, then restart Home Assistant.
4. Go to **Settings**, **Devices and services**, **Add integration**, and choose **Panel Assistant**.

## Updates

Stable releases are offered by default. On Home Assistant 2026.11 or newer, integration updates appear under **Settings**, **Updates**. Install the update, then restart Home Assistant to load it, following the restart Repair. On supported older versions, download the update in HACS and restart Home Assistant when asked. Updating this integration is separate from [updating the panel app](/manage/updates-and-recovery/). Home Assistant shows a short summary of each update; the [release notes](/release-notes/) have the full list of changes.

Before moving from 0.9 to 1.0, read [Upgrading to 1.0](/manage/upgrade-to-1-0/), including its backup steps. A panel that runs the 1.0 app cannot go back to 0.9. Installing an older version is not safe; use the guide's backup recovery instructions if you need to go back.

## What you get

- **The installer.** Adding a panel is a guided flow inside Home Assistant. It checks the panel, installs the panel app over the network or [over USB](/install/install-over-usb/), starts it, and only then creates the device. A panel already running the app is adopted rather than reinstalled.
- **A device per panel.** Each panel appears under Devices and services with a status sensor and downloadable diagnostics, redacted so they can be shared when you ask for help.
- **All your panels in one place.** Administrators can choose a panel from the Panel Assistant sidebar and use its own web interface inside Home Assistant. The picker starts with **All panels**, listed first and apart from the panels, and opening the sidebar shows it.
- **Settings and logs for every panel.** Under **All panels**, two tabs cover every panel at once, including panels added later:
  - **Settings** holds the **Panel logs** card: one log destination for all panels (Off, Home Assistant log, Syslog over UDP or TCP, or HTTP), the app log level (default Warning) and the system log level (default Off). For Syslog and HTTP, enter the host or URL and a port; you can also copy the lines to the Home Assistant log. While the destination is Off, panels send nothing. A destination saved on a panel by an older app version is offered as a choice until one is set.
  - **Logs** shows the lines received from every connected panel, newest first, with the panel's name, time, source (app or system), level and tag. Filter by panel, source and minimum level; the list updates live. Lines are kept in memory only, up to 500 a panel since Home Assistant started, and are never saved.

  This replaces **Panel logs (all panels)** in each panel's Configure dialog.

## Help and feedback

Panel Assistant is new and evolving quickly. A panel that is already installed is updated from its update entity in Home Assistant, as described in [Updates and recovery](/manage/updates-and-recovery/). Feedback is welcome in the [issues](https://github.com/panel-assistant/ha-integration/issues) and on [Discord](https://panel-assistant.io/go/discord).

## If you used the earlier 0.1.0 integration

Remove the old integration entry under Devices and services, then remove its download from Marketplace or HACS. Find Panel Assistant there again and install version **0.9.0** before the first restart. In Marketplace, open the repository’s three-dot menu and choose **Install another version**; in HACS, choose **Redownload**. Pick version **0.9.0**. Restart Home Assistant, then add the integration again using your panel's hostname or address.

If you have already installed Panel Assistant 1.0, follow [if a move was not finished](/manage/upgrade-to-1-0/#if-a-move-was-not-finished) before changing versions.

A panel from that time still runs the old ha-paneld app. Panel Assistant 1.0 cannot move it to the new app: install Panel Assistant 0.9.0 first (in Marketplace, choose **Install another version** from the repository’s three-dot menu; in HACS, choose **Redownload**; pick version **0.9.0**), add the panel and move it with its Repair, then update to 1.0.
