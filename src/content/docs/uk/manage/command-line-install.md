Інсталятор командного рядка видалено. Додавайте й оновлюйте панелі через Panel Assistant у Home Assistant.

Натомість додавайте й оновлюйте панелі з [Home Assistant](/uk/install/installing-ha-paneld/) за допомогою Panel Assistant. Панель, встановлена скриптом, продовжує працювати. Додайте її до Panel Assistant: її буде підключено, а не перевстановлено, після чого Panel Assistant пропонуватиме оновлення.

## Увімкнення ADB через мережу

На деяких панелях Tuya TPA10 і Smatek ADB спочатку працює лише через USB. Під’єднайте кабель USB і ввімкніть мережевий ADB, перш ніж додавати панель у Home Assistant:

```sh
adb devices                   # accept the on-screen RSA prompt if shown
adb root                      # if this firmware supports it
adb tcpip 5555                # expose adb on the network; this resets on reboot
adb connect 192.168.1.50:5555 # replace this address with the panel's address
```

## Видалення ha-paneld з панелі

Виберіть **Видалити Panel Assistant з цієї панелі** в розділі **Налаштувати** у Home Assistant. У 1.0.0-rc1 виберіть, чи має Home Assistant забути панель, а потім натисніть **Надіслати**. У ще не випущеній версії 1.0.0-rc2 цей пункт називається **Видалити з цієї панелі**, а успішне видалення завжди видаляє її запис у Home Assistant. Panel Assistant повертає панелі її власний головний екран і видаляє застосунок панелі. Спочатку прочитайте [Перш ніж видаляти ha-paneld](/uk/manage/removal-risks/).

## Способи доступу та режим безпеки

Рекомендації профілю обладнання мають лише інформаційний характер. Вибір профілю не означає згоди на вимкнення пакетів, постійне ввімкнення ADB, встановлення привілейованого ПЗ чи зміну налаштувань дисплея. Пакети, які ви вже приборкали на картці [пакетів виробника](/uk/manage/vendor-packages/), і далі приборкуються після кожного завантаження.

[Посилений режим безпеки](/uk/manage/security-mode/) вимагає, щоб людина біля панелі підтверджувала окремі віддалені дії зі значними наслідками. Увімкнути його можна лише на панелі. Поки він увімкнений, мережевий ADB недоступний, тому перед встановленням чи оновленням через ADB поверніть панель у звичайний режим на самій панелі.
