## What it is

The wall panels sold as smart-home controllers are mostly slow Android tablets behind a bit of glass, and a Home Assistant dashboard is a heavy page to put in front of one. ha-paneld is an Android app that renders the dashboard on the panel itself and subscribes only to the entities that dashboard actually uses, instead of the whole state machine.

It also publishes the panel's own hardware to Home Assistant over MQTT discovery, so the screen, LEDs, buttons, sensors and relays turn up as entities without per-device YAML. What a given panel exposes depends on the model, and the entities follow the same conventions across makes.

This is for dedicated wall panels, not for phones.

## Where the project stands

ha-paneld is pre-1.0. It is sideloaded rather than installed from Google Play, and its [releases](https://github.com/maxlyth/ha-paneld/releases) come as release candidates before each stable version. Hardware support is uneven and is tracked per model, so the [panel list](/install/supported-panels/) is worth reading before you commit to a device.

A [Home Assistant custom integration](/home-assistant/custom-integration/) is being built alongside the app. It has not been released yet.

This site is new. It is an entry point rather than a complete manual, and the reference documentation still lives with the code in the [ha-paneld repository](https://github.com/maxlyth/ha-paneld/tree/main/docs). Every page here links to the source it summarises.
