## Comments on these pages

Every page has a comments section at the bottom. With a GitHub account you can comment and reply there directly. Without one, open **Comment without a GitHub account** under the comments and post from the form. Either way the comment lands in the same discussion in the [website's GitHub Discussions](https://github.com/panel-assistant/panel-assistant.io/discussions), so a correction or a tip stays next to the page it is about.

## Problems and bugs

Report a problem with Panel Assistant in the [issue tracker](https://panel-assistant.io/go/issues).

## Chat

For a quick question or a conversation, join the [Discord server](https://panel-assistant.io/go/discord).
