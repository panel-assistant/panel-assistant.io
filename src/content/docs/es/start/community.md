## Comentarios en estas páginas

Cada página tiene una sección de comentarios al final. Con una cuenta de GitHub puedes comentar y responder allí directamente. Si no tienes una, abre **Comentar sin una cuenta de GitHub** debajo de los comentarios y publica desde el formulario. En ambos casos, el comentario aparece en la misma conversación de las [GitHub Discussions del sitio web](https://github.com/panel-assistant/panel-assistant.io/discussions), de modo que una corrección o un consejo se queda junto a la página a la que se refiere.

## Problemas y errores

Informa de un problema con Panel Assistant en el [gestor de incidencias](https://panel-assistant.io/go/issues).

## Chat

Para una pregunta rápida o una conversación, únete al [servidor de Discord](https://panel-assistant.io/go/discord).
