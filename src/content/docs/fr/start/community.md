## Commentaires sur ces pages

Chaque page comporte une section de commentaires en bas. Avec un compte GitHub, vous pouvez y commenter et répondre directement. Sans compte, ouvrez **Commenter sans compte GitHub** sous les commentaires et publiez depuis le formulaire. Dans les deux cas, le commentaire rejoint la même discussion dans les [GitHub Discussions du site](https://github.com/panel-assistant/panel-assistant.io/discussions), afin qu’une correction ou une astuce reste à côté de la page qu’elle concerne.

## Problèmes et bugs

Signalez un problème avec Panel Assistant dans l’[outil de suivi des problèmes](https://panel-assistant.io/go/issues).

## Discussion

Pour une question rapide ou une conversation, rejoignez le [serveur Discord](https://panel-assistant.io/go/discord).
